# Identifiers this tree has deliberately removed.
#
# `scripts/check_retired_identifiers.py` fails the commit when any of these
# still occurs in a tracked `.thy` file -- in code or in prose. It exists
# because Isabelle does not reject every surviving use of a removed name:
# inside `assumes`, an unknown lowercase identifier silently becomes a free
# variable, so the locale keeps building while its assumption stops saying
# what it was written to say. Deleting `DG_Transfer_Combinators.thy` turned
# three `call_fwd_ok` assumptions into statements about an arbitrary function
# named `enter_local`, and every session stayed green.
#
# Append a name here when you remove an API. Remove it again -- explicitly --
# if a later design deliberately reuses the name.
#
# Matching is whole-word, so `dgs_caller_cont` does not match `caller_cont`.
# Deliberately NOT listed: `caller_cont`, `combine_env`, `combine_assign`.
# Prose across this tree names record fields by their role rather than by the
# `dgs_`-prefixed field name, and `src/Framework/README.md` documents that
# convention; those three are live vocabulary, not dead references.
