Goblint Formalization · src/Solver/

TD solver bridge

This layer connects our function-style equation system (rhs, is_post_fixpoint in src/Equations/) to the vendored AFP top-down solver, proves that td_analyse returns a post-fixpoint, and lifts that to collecting-semantics soundness per abstract domain. Algorithm correctness lives in the external TD session; here we state interface assumptions and wire the result into Constraint_System_Sound.

What we prove vs import
  • Imported: TD algorithm returns a partial solution on the reach set from the queried entry (TD_plain.partial_correctness).
  • Proved here: That solution read back as td_analyse satisfies is_post_fixpoint for our rhs, via make_rhs_tree_correspondence.
  • Proved downstream: Post-fixpoints over-approximate cfg_collect (post_fixpoint_sound, exit_sound).

1TD external

Assumptions we discharge per program

TD correctness is imported; our proofs assume the strategy forest for the whole program is well-formed for TD's solver:

  • TD_plain.solve_dom on make_rhs_tree (to_cfg c) tf join bot s0 at cfg_entry (to_cfg c) — the TD dominance side condition for the entry-rooted forest.
  • cfg_in_reach (reach side condition): every program point v lies in reach T (TD_plain_Interp_solve T v0) v0 from the CFG entry. Open hypothesis (P2): structural property of the TD solver's internal reach set; not automatically dischargeable from CFG shape.
Not in this folder

Analysis packaging (sign_analysis_config, ivl_analysis_config, run_analysis) is in Pipeline/Pipeline.thy.

2Interface

TD_Interface.thy repackages our monotone rhs into TD's strategy-tree monad and defines the executable analysis function.

Function-style RHS (input)

rhs :: cfg
    => 'a::ord domain_transfer
    => ('a abs_state => 'a abs_state => 'a abs_state)
    => 'a abs_state   (* bot, join unit *)
    => 'a abs_state   (* s0 at entry *)
    => pp => (pp => 'a abs_state) => 'a abs_state

Curried as env v last. Monotone in env (make_rhs_mono / rhs_mono from Constraint_System).

Bridge definitions

definition make_rhs g tf join bot s0 v env =
  rhs g tf join bot s0 env v

fun rhs_tree_fold tf join acc [] = Answer acc
| rhs_tree_fold tf join acc ((u,a)#ps) =
    Query u (λsu. rhs_tree_fold tf join (join acc (apply_tf tf a su)) ps)

definition make_rhs_tree g tf join bot s0 v =
  rhs_tree_fold tf join acc0 (predecessor_list g v)
  where acc0 = (if v = cfg_entry g then join bot s0 else bot)

definition td_analyse c tf join bot s0 v =
  lookup_bot (TD_plain_Interp_solve (make_rhs_tree (to_cfg c) …) (cfg_entry (to_cfg c))) v
NameRole
make_rhs_tree One strategy tree per program point v: fold predecessor edges with Query / Answer, seeding entry with join bot s0.
env_map / lookup_bot Convert between pp ⇒ abs_state and TD's partial map type.
td_analyse Run TD solve from cfg_entry (to_cfg c); return λv. lookup_bot σ v.

  • rhs_tree_fold_traverse_env_map — fold semantics vs environment traversal.
  • make_rhs_tree_correspondence key — TD tree evaluation matches make_rhs / predecessor fold of rhs.
  • rhs_eq_fold_predecessor_list — rhs as join of predecessor transfers.
  • part_solutionD — extract facts from TD's part_solution.

3Post-fixpoint proof

Main deliverable of the interface layer: solver output satisfies our equational post-fixpoint predicate.

Target theorem
theorem td_analyse_post_fixpoint:
  assumes fin: "finite (edges (to_cfg c))"
  assumes cfi: "comp_fun_idem join_abs"
  assumes join_sym: "⋀x y. join_abs x y = join_abs y x"
  assumes solve_dom:
    "TD_plain.solve_dom (make_rhs_tree (to_cfg c) tf join_abs bot_abs s0)
       (cfg_entry (to_cfg c))"
  assumes cfg_in_reach: "⋀v. v ∈ reach … (cfg_entry (to_cfg c))"
  shows "is_post_fixpoint (to_cfg c) tf join_abs bot_abs s0
           (td_analyse c tf join_abs bot_abs s0)"

Where is_post_fixpoint g tf join bot s0 env means ∀v. rhs g tf join bot s0 env v ≤ env v (Constraint_System.thy).

Proof idea

  1. Run TD_plain_Interp_solve on the entry-rooted strategy forest.
  2. Import TD_plain.partial_correctness: partial solution on the reach set from entry.
  3. At each v ∈ reach …, use make_rhs_tree_correspondence to relate TD's eq T v σ to our predecessor-fold RHS.
  4. Read values back through lookup_bot / td_analyse_def to obtain is_post_fixpoint.

4Domain soundness

TD_Soundness.thy combines post-fixpoint soundness with abstract transfer-function soundness to state exit-point collecting coverage.

Generic (abstract locale)

theorem td_solver_sound:
  assumes tf_sound_assign / tf_sound_assume / tf_sound_assume_not
  assumes s0_sound: "s ∈ gamma_state s0"
  assumes exit_in_collect:
    "t ∈ cfg_collect (to_cfg c) {s} (cfg_exit (to_cfg c))"
  assumes fin_cfg, sup_cfi, td_solve_dom, td_cfg_in_reach
  shows "t ∈ gamma_state (td_analyse c tf (⊔) bot s0 (cfg_exit (to_cfg c)))"

Proof: td_analyse_post_fixpoint then exit_sound from Constraint_System_Sound.

Premise shape

Both instantiations still assume TD_plain.solve_dom and the reach inclusion td_cfg_in_reach on make_rhs_tree (to_cfg c) sign_tf/ivl_tf …. Initial-store soundness is s ∈ gamma_state s0 (sign or interval locale).
