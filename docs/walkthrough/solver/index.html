Goblint Formalization · src/Solver/

TD solver bridge

This layer connects our function-style equation system (rhs in src/Equations/) to the vendored AFP top-down solver. Per-program-point td_analyse c … v is proved sound against cfg_collect via post_fixpoint_sound_at and td_env_at_path_step_le. Algorithm correctness lives in the external TD session; the only open operational hypothesis is P1 (⋀v. TD_plain.solve_dom … v).

Running example · Program A

2Interface

TD_Interface.thy repackages our monotone rhs into TD's strategy-tree monad and defines the executable analysis function.

Function-style RHS (input)

rhs :: cfg
    => 'a::ord domain_transfer
    => ('a abs_state => 'a abs_state => 'a abs_state)
    => 'a abs_state   (* bot, join unit *)
    => 'a abs_state   (* s0 at entry *)
    => pp => (pp => 'a abs_state) => 'a abs_state

Curried as env v last. Monotone in env (make_rhs_mono / rhs_mono from Constraint_System).

Bridge definitions

definition make_rhs g tf join bot s0 v env =
  rhs g tf join bot s0 env v

fun rhs_tree_fold tf join acc [] = Answer acc
| rhs_tree_fold tf join acc ((u,a)#ps) =
    Query u (λsu. rhs_tree_fold tf join (join acc (apply_tf tf a su)) ps)

definition make_rhs_tree g tf join bot s0 v =
  rhs_tree_fold tf join acc0 (predecessor_list g v)
  where acc0 = (if v = cfg_entry g then join bot s0 else bot)

definition td_analyse c tf join bot s0 v =
  lookup_bot (TD_plain_Interp_solve (make_rhs_tree (to_cfg c) …) (cfg_entry (to_cfg c))) v
NameRole
make_rhs_tree One strategy tree per program point v: fold predecessor edges with Query / Answer, seeding entry with join bot s0.
env_map / lookup_bot Convert between pp ⇒ abs_state and TD's partial map type.
td_analyse Run TD solve from cfg_entry (to_cfg c); return λv. lookup_bot σ v.

Correspondence lemmas (selected)

  • make_rhs_mono Monotonicity of the rhs wrapper — required by TD’s theory.
  • rhs_tree_fold_traverse_env_map Strategy-tree fold agrees with environment-based traversal.
  • make_rhs_tree_correspondence key Evaluating the TD tree at v equals applying rhs at v — the main bridge lemma.
  • rhs_eq_fold_predecessor_list rhs is formally a join over predecessor edge transfers.
  • part_solutionD Extract inequalities from TD’s partial solution certificate.

3Per-pp collecting soundness

Main deliverable of TD_Soundness.thy: at each queried program point v0, td_analyse over-approximates cfg_collect.

Target theorem

td_analyse_collect_sound_at — At the queried program point v₀, the TD solver’s abstract answer over-approximates CFG collecting semantics for stores reachable from S. 

theorem td_analyse_collect_sound_at:
  assumes entry_path:
    "cfg_path (to_cfg c) (cfg_entry (to_cfg c)) es v0"
  assumes td_solve_dom:
    "TD_plain.solve_dom (make_rhs_tree (to_cfg c) tf (⊔) bot s0) v0"
  shows "cfg_collect (to_cfg c) S v0
         ≤ gamma_state (td_analyse c tf (⊔) bot s0 v0)"

Uses locale td_cfg_plain_solver, td_env_at v0, path-local td_env_at_path_step_le, and post_fixpoint_sound_at from Constraint_System_Sound.thy (not global is_post_fixpoint on the whole map).

Proof idea

  1. td_analyse c … v0 = td_env_at v0 v0 (td_analyse_eq_env_at).
  2. Run TD at root v0; import TD_plain.partial_correctness on reach … v0.
  3. td_env_at_rhs_le / td_env_at_path_step_le from partial solution + eq_le_mlup_imp_rhs_le.
  4. post_fixpoint_sound_at at v0 with path-shaped step_le.

4Domain soundness

TD_Soundness.thy combines post-fixpoint soundness with abstract transfer-function soundness to state exit-point collecting coverage.

Generic (abstract locale)

td_solver_sound — Exit collecting membership implies the concrete final store is in γ of td_analyse at exit (any domain satisfying the transfer axioms). 

theorem td_solver_sound:
  assumes tf_sound_assign / tf_sound_assume / tf_sound_assume_not
  assumes s0_sound: "s ∈ gamma_state s0"
  assumes exit_in_collect:
    "t ∈ cfg_collect (to_cfg c) {s} (cfg_exit (to_cfg c))"
  assumes fin_cfg, entry_path, td_solve_dom: "⋀v. TD_plain.solve_dom … v"
  shows "t ∈ gamma_state (td_analyse c tf (⊔) bot s0 (cfg_exit (to_cfg c)))"

Proof: td_analyse_collect_sound_at at exit (cfg_path entry → exit) with singleton store {s}.

Domain instantiations

TheoremIn words
sign_analysis_sound td_solver_sound for sign transfers: exit collecting ⇒ final store in sign γ at exit.
interval_analysis_sound Same for interval domain and ivl_tf.
Premise shape

Both instantiations assume ⋀v. TD_plain.solve_dom (make_rhs_tree …) v and a cfg_path from entry to exit. Initial-store soundness is s ∈ gamma_state s0. No td_cfg_in_reach (P2 closed).
