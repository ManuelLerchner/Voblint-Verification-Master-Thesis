Goblint Formalization · IMP2

IMP2 source language: syntax and small-step semantics

The src/IMP2/ layer is the operational front door of the formalization: a native command datatype, expression extensions over HOL-IMP, and a small-step relation (c, s) → (c', s') with reflexive-transitive closure to SKIP. There is no big-step semantics, collecting semantics, or separate separate IMP2_Semantics or IMP2_Collecting theories here — evaluation and small-step live in IMP2_SmallStep; collecting and runs_to are in CFG/Collecting.

Proof status · IMP2 layer

No sorry in src/IMP2/. Terminating runs are linked to CFG exit reachability via runs_to_iff_small_step in CFG/Collecting/CFG_Runs_To_Bridge.thy, not in this folder.

Terminating run (informal)

A run from initial store s finishes when (c, s) →* (SKIP, t). Downstream, runs_to c s t is equivalent to that small-step star (proved in CFG collecting, not here).

Store

type_synonym store = vname ⇒ int

vname is HOL-IMP’s string type. Assignment uses s(x := v) from HOL.

Arithmetic aexp

BaseN "AExp.aexp"     (* Nipkow subtree at leaves *)
| Plus  aexp aexp
| Minus aexp aexp      (* extension *)
| Times aexp aexp      (* extension *)

abbrev: N n ≡ BaseN (AExp.N n)
abbrev: V x ≡ BaseN (AExp.V x)

Pattern matches on leaves must spell BaseN (AExp.N _) — abbreviations do not unfold in fun/case.

Boolean bexp

BaseB "BExp.bexp"
| Not | And | Or       (* Or, Eq: extensions *)
| Less aexp aexp
| Eq   aexp aexp

abbrev: Bc v ≡ BaseB (BExp.Bc v)

03Small-step semantics

IMP2_SmallStep.thy — expression evaluation and operational rules mirroring HOL-IMP.Small_Step.

aval / bval

Defined in SmallStep, not a separate semantics theory

aval (BaseN a) s   = AExp.aval a s
aval (Plus a b) s  = aval a s + aval b s
...

bval (BaseB b) s   = BExp.bval b s
bval (Less a b) s  = (aval a s < aval b s)
bval (Eq a b) s    = (aval a s = aval b s)

small_step (infix →)

Assign:  (x ::= a, s) → (SKIP, s(x := aval a s))
Seq1:    (SKIP ;; c2, s) → (c2, s)
Seq2:    (c1, s) → (c1', s') ⟹ (c1 ;; c2, s) → (c1' ;; c2, s')
IfTrue:  bval b s ⟹ (IF b THEN c1 ELSE c2, s) → (c1, s)
IfFalse: ¬ bval b s ⟹ ... → (c2, s)
While:   (WHILE b DO c, s) → (IF b THEN c ;; WHILE b DO c ELSE SKIP, s)

Reflexive-transitive closure

small_steps  (infix "→*" 55)
where "x →* y ≡ star small_step x y"

Finishing store t: (c, s) →* (SKIP, t).

Executable predicate

code_pred small_step .

Predicate compiler export for experimentation and example proofs.

Tiny example · assign sequence

From Goblint_Formalization.thy — swap x and y via a temp (three assigns, then SKIP):

example_swap =
  ''tmp'' ::= V ''x'' ;;
  ''x''   ::= V ''y'' ;;
  ''y''   ::= V ''tmp''

Proved on the full pipeline with runs_to / →* after CFG import. The collecting demo in Example_CFG_Collecting_Equiv.thy uses a similar x := 5; y := x + 1 shape — see pipeline walkthrough.

Non-termination witness

while_true_skip_no_finish: a WHILE (Bc True) DO … never reaches (SKIP, t). The incrementing-x corollary shows divergence is not vacuously excluded by the small-step rules alone.

04Downstream links

IMP2 stops at small-step; CFG and collecting connect execution to analysis.

CFG layer

IMP2_to_CFG.thy compiles com to a control-flow graph (to_cfg / compile). Paths carry actions for transfer-function composition; see CFG path infrastructure.

CFG collecting

cfg_collect over-approximates stores at program points. runs_to_iff_small_step and small_step_runs_to / runs_to_small_step live in CFG_Runs_To_Bridge.thy — the bidirectional link between runs_to and (c, s) →* (SKIP, t).

THEOREM (downstream) runs_to_iff_small_step CFG/Collecting 
runs_to c s t  ⟺  (c, s) →* (SKIP, t)

Not proved in src/IMP2/. Import CFG_Runs_To_Bridge for the full small-step ↔ CFG collecting chain.

Thesis alignment

Soundness is stated against cfg_collect at every program point. IMP2 supplies the operational steps; the equation system + TD solver soundly over-approximate the CFG fixpoint. See end-to-end pipeline.
