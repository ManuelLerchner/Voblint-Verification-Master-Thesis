From CFG + abstract domain to a sound constraint system

src/Equations/ packages per-edge transfer functions into a monotone right-hand side rhs, defines when an environment is a post-fixpoint, and proves that any such environment soundly over-approximates CFG collecting semantics cfg_collect at every program point. Downstream, src/Solver/TD_Interface.thy turns rhs into the tree format the vendored TD solver consumes.

  -- EA_Nop · EA_Assign · EA_Assume · EA_AssumeNot

The same record works for Sign, Interval, Octagon, …: each domain instantiates the three transformers and proves they are sound w.r.t. gamma_state (in src/Domains/).

One-step operator at node v

For predecessors (u, a, v) ∈ edges g, collect apply_tf tf a (env u) and join with abs_join_set (Finite_Set.fold join bot). At cfg_entry g, also insert the initial abstract state s0.

flowchart TB subgraph preds ["Predecessors of v"] U1["(u₁, a₁, v)"] U2["(u₂, a₂, v)"] Uk["…"] end subgraph images ["Abstract images"] I1["apply_tf tf a₁ (env u₁)"] I2["apply_tf tf a₂ (env u₂)"] Ik["…"] end subgraph join ["rhs at v"] J["abs_join_set join bot { images }"] S0["+ s0 when v = cfg_entry g"] RHSv["rhs g tf join bot s0 env v"] J --> RHSv S0 -.-> RHSv end U1 --> I1 U2 --> I2 Uk --> Ik I1 --> J I2 --> J Ik --> J
DEF rhs 
rhs g tf join_abs bot_abs s0 env v =
  let preds = {(u, a) | u a. (u, a, v) ∈ edges g};
      vals  = image (λ(u, a). apply_tf tf a (env u)) preds;
      base  = if v = cfg_entry g then insert s0 vals else vals
  in  abs_join_set join_abs bot_abs base

Type: pp ⇒ (pp ⇒ 'a abs_state) ⇒ 'a abs_state — the TD_plain locale expects exactly this “environment in, abstract state out” shape.

Supporting lemmas (construction)

  • abs_join_set_empty — join of empty set is bot.
  • rhs_no_predecessors_not_entry — non-entry with no preds ⇒ bot.
  • rhs_entry_no_predecessors — entry with no preds ⇒ join of {s0}.
  • mem_image_le_fold, fold_join_image_mono — fold infrastructure.
  • rhs_mono solver prerequisite — rhs monotone in env pointwise.

02Post-fixpoint predicate

is_post_fixpoint means the environment is above the one-step rhs operator at every program point — a standard post-fixpoint of the chaotic iteration.

DEF is_post_fixpoint predicate 
is_post_fixpoint g tf join_abs bot_abs s0 env  ≡
  ∀v. rhs g tf join_abs bot_abs s0 env v ≤ env v

Read: for all nodes v, the rhs join over predecessor transfer images (plus s0 at entry) is below or equal to the stored abstract value env v in the abstract order. Equivalently, env is a post-fixpoint of the one-step operator λenv. λv. rhs … env v.

flowchart LR subgraph op ["One-step operator"] E1["env"] R["rhs g tf join bot s0 env v"] E1 --> R end subgraph pf ["Post-fixpoint"] E2["env v"] R -->|"≤ (abstract order)"| E2 end subgraph collect ["Collecting semantics"] C["cfg_collect g S v
set of concrete stores"] G["gamma_state (env v)"] C -->|"must be ⊆"| G end pf -.->|"post_fixpoint_sound"| collect
Not a fixpoint equation

The formal definition uses rhs … ≤ env v, not equality rhs … = env v. Soundness only needs one-sided inclusion; the TD solver may return a strictly larger (more conservative) abstract state and still satisfy is_post_fixpoint.

03Soundness theorems

Constraint_System_Sound.thy — inside locale sound_domain: transfer-function soundness ⇒ per-edge collecting step ⇒ global cfg_collect inclusion.

Proof spine (inside the file)

  1. edge_collect_apply_tf_sound — concrete edge collecting factors through apply_tf.
  2. apply_tf_le_rhs — each predecessor image sits below the rhs join at v.
  3. collect_pp_abstract_sound — one step of collect_pp through abstract env.
  4. s0_le_rhs_entry — initial abstract state below rhs at entry.
  5. post_fixpoint_sound — lift to cfg_collect via least fixpoint.
  6. exit_sound — corollary projecting to the CFG exit node only.
LEMMA collect_pp_abstract_sound 
is_post_fixpoint g tf (⊔) bot s0 env
⟹ collect_pp g (λv. gamma_state (env v)) v ⊆ gamma_state (env v)

Pointwise step: one layer of collecting semantics stays inside the concretisation of env v.

THEOREM post_fixpoint_sound per program point 
is_post_fixpoint g tf (⊔) bot s0 env
⟹ S ≤ gamma_state s0
⟹ ∀v. cfg_collect g S v ≤ gamma_state (env v)

Main result. At every program point v, the abstract value env v soundly over-approximates all stores reachable in collecting semantics from initial set S. Uses cfg_collect_def and lfp_lowerbound from the CFG collecting theory imported via CFG_Runs_To_Bridge.

COROLLARY exit_sound exit only 
is_post_fixpoint (to_cfg c) tf (⊔) bot s0 env
⟹ t ∈ cfg_collect (to_cfg c) {s} (cfg_exit (to_cfg c))
⟹ t ∈ gamma_state (env (cfg_exit (to_cfg c)))

Specialises post_fixpoint_sound to the exit node and a singleton initial store {s}. This is the hook used by the pipeline when combining with runs_to / cfg_collect at exit from the collecting layer.

Per-pp vs exit-only
  • post_fixpoint_sound — universal over all v ∈ pp; needed for point-map / invariant soundness in Pipeline.thy.
  • exit_sound — only the exit program point; enough for “terminating store in collect c {s}” style top-level theorems.
