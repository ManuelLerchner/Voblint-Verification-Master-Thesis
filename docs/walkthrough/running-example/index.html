01

IMP2 — operational execution

Layer: imp2 walkthrough · IMP2_SmallStep.thy

Small-step proof sketch

(x := 5, s₀) →* (SKIP, s₁)   s₁ x = 5
(y := x+1, s₁) →* (SKIP, t)   t = s₁[y := 6]
(seq, s₀) →* (SKIP, t)         by seq_comp

Lemmas used

  • star.step Single small-step transitions build reflexive-transitive closure.
  • seq_comp Chaining stars through intermediate commands (here: both assignments).
  • small_step_runs_to CFG_Runs_To_Bridge Star to SKIP implies runs_to — turns the operational proof into the collecting spec.

In the repo: collecting_example_runs_to in Example_CFG_Collecting_Equiv.thy (lines 47–60).

Example_CFG_Collecting_Equiv.thy lines 47–60
lemma collecting_example_runs_to:
  "runs_to collecting_example_prog collecting_example_s0 collecting_example_t"
proof -
  let ?s1 = "collecting_example_s0(''x'' := 5)"
  have step1: "(''x'' ::= N 5, collecting_example_s0) →* (SKIP, ?s1)"
    by (auto intro: star.step)
  have step2: "(''y'' ::= Plus (V ''x'') (N 1), ?s1) →* (SKIP, collecting_example_t)"
    unfolding collecting_example_t_def
    by (auto intro: star.step)
  have "(collecting_example_prog, collecting_example_s0) →* (SKIP, collecting_example_t)"
    unfolding collecting_example_prog_def
    using seq_comp[OF step1 step2] .
  thus ?thesis by (rule small_step_runs_to)
qed

Sign domain — abstract stores

Layer: domains walkthrough · Sign_Domain.thy

Sign abstract values: SBot < SNeg < SZero < SPos < STop. Initial config sign_analysis_config s₀ maps every variable to STop (unknown), which γ-concretizes to all integers — so s₀ ∈ γ(ac_init …).

Edge / actionConcreteSign abstract (idea)Soundness lemma
x := 5 x ↦ 5 x ↦ SPos (or SZero for literal 0) assign_sign_sound
y := x+1 y ↦ 6 y ↦ SPos from x plus const aval_sign_sound
  • sound_domain / gamma_sign Abstract values denote sets of integers; ⊥ is empty; order is subset inclusion on concretizations.
  • sign_tf_sound All three edge kinds (assign / assume / assume-not) satisfy the generic transfer axioms.
  • assign_sign_sound Soundness of x := 5 and y := x+1 on Program A.

Executable spot checks (different program y := x + x): Example_Sign_Analysis. Program A uses the same transfer lemmas with Plus (V ''x'') (N 1).

Sign_Domain.thy Program A edges (conceptually)
(* x := 5 on s₀ with all vars STop *)
assign_sign ''x'' (N 5) (λ_. STop)           (* x ↦ SPos *)

(* y := x + 1 after x ↦ SPos *)
assign_sign ''y'' (Plus (V ''x'') (N 1))
         ((λ_. STop)(''x'' := SPos))           (* y ↦ SPos — 6 ∈ γ y *)

TD solver — computed environment

Layer: solver walkthrough · TD_Soundness.thy

Thmtd_analyse_collect_sound_at

Whatever the TD solver returns at program point v is a sound over-approximation of cfg_collect at v (given solve_dom). 

TD_plain.solve_dom (make_rhs_tree …) v
⟹ cfg_collect g S v ⊆ γ_state (td_analyse c tf … v)

Pipeline — end-to-end theorems

Layer: pipeline walkthrough · Pipeline.thy, Voblint_Formalization.thy

Thmpipeline_invariant_sound

Packages solver + domain soundness: the full run_analysis result is sound at every program point, not only at exit. 

∀ v. cfg_collect (to_cfg c) {s} v
      ≤ γ_state (run_analysis cfg c v)

Specialize v = cfg_exit (to_cfg c) with runs_to c s t:

collecting_example_runs_to → pipeline_sound_runs_to_runs → sign_pipeline_sound (sign cfg) → t ∈ γ_sign (run_analysis … exit)

Program A is not exported as a top-level theorem, but it is the same proof pattern as voblint_sign_sound on Program B.

Voblint_Formalization.thy voblint_sign_sound
theorem voblint_sign_sound:
  assumes runs: "runs_to c s t"
  assumes td_solve_dom: "⋀v. TD_plain.solve_dom (make_rhs_tree …) v"
  shows "t ∈ sign_domain.gamma_state
           (run_analysis (sign_analysis_config s) c (cfg_exit (to_cfg c)))"
  by (rule sign_pipeline_sound …)

CVariable swap (operational correctness)

Program C shows IMP2 + runs_to without going through the sign pipeline headline. Given arbitrary initial store s, execution swaps x and y.

Program

tmp := x;
x := y;
y := tmp

Correctness goal

runs_to example_swap s t
⟹ t ''x'' = s ''y'' ∧ t ''y'' = s ''x''

Lemma trace

StepLemmaIn words
Existential run example_swap_runs_to From any s, some exit store is reachable — proved by composing small-step stars for each assignment.
Functional spec example_swap_correct If runs_to example_swap s t, then t swaps x and y relative to s.
Bridge runs_to_small_step Unpack runs_to into an operational →* trace for the correctness proof.
Assign reasoning star_Assign_eq Relate assignment stars to explicit store updates (s(x := e)).

lemma example_swap_correct:
  "runs_to example_swap s t ⟹ t ''x'' = s ''y'' ∧ t ''y'' = s ''x''"
proof -
  assume "runs_to example_swap s t"
  hence star: "(example_swap, s) →* (SKIP, t)"
    by (rule runs_to_small_step)
  …
  show "t ''x'' = s ''y'' ∧ t ''y'' = s ''x''"
    using t_eq s2_eq s1_eq by simp
qed
