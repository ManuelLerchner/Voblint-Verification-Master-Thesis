IMP source to sound sign-analysis result

00Running example

A tiny program we will follow all the way to the end.

Program c

x ::= N 1;;
WHILE Less (N 0) (V x) DO
  x ::= Plus (V x) (N (-1))

Initial concrete store s

s = (λ_. 0)

Concrete big-step terminates with t x = 0.

Target theorem
t ∈ sign_domain.gamma_state
      (run_analysis (sign_analysis_config s) c
        (cfg_exit (to_cfg c)))

i.e. the abstract value of x at the program exit is in {SZero, STop}, so its concretization contains 0.

theorem post_fixpoint_sound:
  is_post_fixpoint g tf join_state bot_state s0 env
  ⟹  s ∈ gamma_state s0
  ⟹  cfg_collect g {s} v ⊆ gamma_state (env v)
Example

The env p1 ↦ x:SPos, p2 ↦ x:STop, p3 ↦ x:STop, p4 ↦ x:SNeg, p5 ↦ x:STop is a post-fixpoint of rhs. By post_fixpoint_sound, γ_state (env p5) ⊇ collect c {s} ⊇ {t}. So t x = 0 ∈ γ_sign STop. ✓

Pipeline.thy

definition domain_transfer_sound gamma tf

CFG layer — graph structure

src/CFG/CFG_Def.thy

type_synonym pp = nat datatype edge_action = EA_Nop | EA_Assign vname aexp | EA_Assume bexp | EA_AssumeNot bexp record cfg = cfg_entry :: pp cfg_exit :: pp cfg_edges :: (pp × edge_action × pp) set cfg_nodes g ≡ { cfg_entry g, cfg_exit g } ∪ { u | (u,_,_) ∈ cfg_edges g } ∪ { v | (_,_,v) ∈ cfg_edges g } predecessors g v ≡ { (u, a) | (u, a, v) ∈ cfg_edges g } successors g u ≡ { (a, v) | (u, a, v) ∈ cfg_edges g } -- the only structural assumption used downstream cfg_wf g ≡ cfg_entry g ≠ cfg_exit g ∧ finite (cfg_edges g) ∧ ∀ (u, _, v) ∈ cfg_edges g. u ∈ cfg_nodes g ∧ v ∈ cfg_nodes g

CFG layer — concrete transformers

src/CFG/CFG_Collecting.thy · src/CFG/CFG_Path.thy

-- per-edge concrete action over store sets edge_collect EA_Nop S = S edge_collect (EA_Assign x a) S = { s(x := aval a s) | s ∈ S } edge_collect (EA_Assume b) S = { s ∈ S | bval b s } edge_collect (EA_AssumeNot b) S = { s ∈ S | ¬ bval b s } -- compose along a recorded edge-action list path_collect [] S = S path_collect ((a, _) # es) S = path_collect es (edge_collect a S) -- paths in the CFG, with their action labels remembered inductive cfg_path g u es v where empty : cfg_path g v [] v step : (u, a, w) ∈ cfg_edges g ∧ cfg_path g w es v ⟹ cfg_path g u ((a, w) # es) v g ⊢ u →* v ≡ ∃ es. cfg_path g u es v -- reachability

CFG layer — collecting semantics

src/CFG/CFG_Collecting.thy

-- one-step "push" through every incoming edge collect_pp g ρ v ≡ ⋃ { edge_collect a (ρ u) | (u, a, v) ∈ cfg_edges g } -- collecting semantics as a least fixpoint of single-step push, -- with the initial set S injected at the entry node cfg_collect g S ≡ lfp ( λρ v. if v = cfg_entry g then S ∪ collect_pp g ρ v else collect_pp g ρ v )

Abstract domain

src/Domains/Abstract_Domain.thy

type_synonym 'a abs_state = vname ⇒ 'a -- The minimum a domain must satisfy for soundness to hold. locale sound_domain fixes γ : 'a ⇒ int set (⊔) : 'a ⇒ 'a ⇒ 'a assumes (D1) γ ⊥ = ∅ (D2) a ≤ b ⟹ γ a ⊆ γ b (D3) a ≤ a ⊔ b ∧ b ≤ a ⊔ b (D4) a ⊔ b = b ⊔ a (D5) a ⊔ (b ⊔ c) = (a ⊔ b) ⊔ c -- pointwise lifting to states γ_state σ ≡ { s | ∀ x. s x ∈ γ (σ x) } bot_state ≡ (λ_. ⊥) (σ₁ ⊔ σ₂) ≡ (λx. σ₁ x ⊔ σ₂ x) -- = join_state Note: comp_fun_commute (⊔) follows from (D4)+(D5). This is what makes Finite_Set.fold (⊔) ⊥ order-independent on finite sets.

∎End-to-end soundness — narrative

Each lemma stated abstractly (math form, no Isabelle escapes), in the order in which the soundness argument actually uses them. The final sub-section composes them into one chain.

Notation

  • c — IMP program; s — initial concrete store; t — concrete final store.
  • g = to_cfg c — compiled CFG; pp — program points.
  • D — abstract domain (think sign); γ — concretization; γ_state : (vname ⇒ D) ⇒ store set.
  • tf — transfer functions (tf_assign, tf_assume, tf_assume_not); apply_tf a — per-edge action a.
  • env : pp ⇒ (vname ⇒ D) — abstract environment computed by the solver.
  • s₀ : (vname ⇒ D) — initial abstract state at the CFG entry.
Step 1

Concrete semantics is the ground truth

Standard big-step semantics, lifted to sets of stores.

L1Determinism of big-step
(c, s) ⇒ t₁ ∧ (c, s) ⇒ t₂ ⟹ t₁ = t₂
L2Compositional shape of collect
collect SKIP S = S collect (x ::= a) S = { s(x := aval a s) | s ∈ S } collect (c₁ ;; c₂) S = collect c₂ (collect c₁ S) collect (IF b …) S = collect c₁ (S ∩ ⟦b⟧) ∪ collect c₂ (S ∩ ⟦¬b⟧) collect (WHILE b DO c) S = lfp F where F X = (S ∪ collect c (X ∩ ⟦b⟧)) ∩ ⟦¬b⟧
L3Monotonicity of collect
S ⊆ S' ⟹ collect c S ⊆ collect c S'

Consequence used downstream. If (c, s) ⇒ t then t ∈ collect c {s}. This is the only fact about the concrete world that the rest of the chain needs.

Step 2

Replace AST reasoning with CFG reasoning

to_cfg c produces a finite CFG whose collecting semantics matches the AST collecting semantics at the exit node.

L4Well-formed compilation
finite (cfg_edges g) cfg_wf g cfg_entry g ≠ cfg_exit g
L5Monotonicity of CFG collecting
S ⊆ S' ⟹ cfg_collect g S v ⊆ cfg_collect g S' v for every v
L6IMP ↔ CFG bridge
cfg_collect (to_cfg c) S (cfg_exit (to_cfg c)) = collect c S

Consequence used downstream. Soundness at the CFG exit transports verbatim back to soundness on the AST.

Step 3

Abstract domain over-approximates concrete operations

L7Galois monotonicity
a ≤ b ⟹ γ a ⊆ γ b σ₁ ≤ σ₂ ⟹ γ_state σ₁ ⊆ γ_state σ₂
L8Join is a sound upper bound
γ a ⊆ γ (a ⊔ b) γ b ⊆ γ (a ⊔ b) γ_state σ₁ ⊆ γ_state (σ₁ ⊔ σ₂) (and symmetric)
L9Lattice laws on the abstract join
comp_fun_commute (⊔) — commutativity + associativity Consequence: Finite_Set.fold (⊔) bot is well-defined and order-independent.
L10Soundness of arithmetic
s ∈ γ_state σ ⟹ aval a s ∈ γ (aval_abs a σ) For Sign: sign_plus / sign_minus / sign_times soundness ⟹ aval_sign_sound.
L11Soundness of edge transfer
For each action a: s ∈ γ_state σ ⟹ edge_collect a {s} ⊆ γ_state (apply_tf tf a σ) For Sign: assign_sign_sound, assume_sign_sound, assume_not_sign_sound.
Step 4

Lift edge soundness to the constraint system

At each node, the equation system performs a join over predecessors of the transferred abstract states.

L12Right-hand side definition
rhs g tf ⊔ bot s₀ env v = ⨆ { apply_tf tf a (env u) | (u, a, v) ∈ edges } ⊔ (if v = cfg_entry g then s₀ else bot)
L13Monotonicity of rhs
env₁ ≤ env₂ ⟹ rhs … env₁ v ≤ rhs … env₂ v for every v Requires: finite (cfg_edges g) comp_fun_commute (⊔) join-ub + join-least + join-monotone apply_tf tf a monotone in its state argument
L14Post-fixpoint ⟹ pointwise over-approximation heart
is_post_fixpoint env ≡ ∀v. rhs … env v ≤ env v is_post_fixpoint env ∧ s ∈ γ_state s₀ ⟹ cfg_collect g {s} v ⊆ γ_state (env v) for every v

Proof of L14 is by induction along paths in the CFG, using L5, L8, L11, L13.

Step 5

Hand the equation system to the TD Top-Down Solver

The TD solver consumes a right-hand side in monadic Answer / Query form. We show our rhs fits that interface, and we get the post-fixpoint guarantee in return.

L15Solver-compatible repackaging
make_rhs g tf ⊔ bot s₀ v env = rhs g tf ⊔ bot s₀ env v (argument reorder)
L16Monadic ↔ direct correspondence
traverse (make_rhs_tree g tf … v) (env_map η) = make_rhs g tf … v η for every η
L17Monotonicity of the packaged rhs
monotone (≤) (≤) (make_rhs g tf ⊔ bot s₀ v) (direct consequence of L13)
L18TD guarantee imported
td_analyse c tf ⊔ bot s₀ = env ⟹ ∀v. rhs … env v ≤ env v
Step 6

Compose into end-to-end soundness

L19Generic pipeline soundness main
Assume: (1) domain_transfer_sound γ tf — packaged L11 (2) s ∈ γ_state s₀ — initial covered (3) (c, s) ⇒ t — program terminates Then: t ∈ γ_state (run_analysis cfg c (cfg_exit (to_cfg c)))

The composition chain

(L18) TD solver run_analysis is a post-fixpoint ↓ (L14) post_fixpoint_sound cfg_collect (to_cfg c) {s} v ⊆ γ_state (env v) for every v ↓ specialize v := cfg_exit (to_cfg c) (L6) bridge lemma collect c {s} ⊆ γ_state (env (cfg_exit ...)) ↓ (c, s) ⇒ t ⟹ t ∈ collect c {s} t ∈ γ_state (run_analysis cfg c (cfg_exit (to_cfg c)))
L20Sign instantiation
Specialize L19 with: D = sign γ = gamma_sign tf = (assign_sign, assume_sign, assume_not_sign) s₀ = λx. sign_of_int (s x) (1) discharged by Sign transfer-function soundness (Sign half of L11) (2) reduces to s x ∈ γ_sign (sign_of_int (s x)) — trivial
L21Per-point invariant strengthening
Drop the specialization v := cfg_exit g in the chain: cfg_collect g {s} v ⊆ γ_state (env v) for every v Yields sign_pipeline_invariant_sound (point-map form). Exit soundness is the v = cfg_exit case (goblint_sign_sound).
Summary in one paragraph

The vendored TD solver guarantees a post-fixpoint of our equation system (L15–L18). A post-fixpoint over-approximates the CFG collecting semantics at every node (L14), because at every node the right-hand side is monotone (L13) and built from sound edge transfers (L11) joined by a sound abstract join (L8) using a lattice that makes folds well-defined (L9). At the exit, CFG collecting equals AST collecting (L6), and the AST collecting captures every concrete terminating store (L2). Therefore the abstract value at the exit concretizes to a superset of { t | (c, s) ⇒ t }. Specializing the domain to sign (L20) gives goblint_sign_sound; at every program point, sign_pipeline_invariant_sound (L21).
