Goblint Formalization · Main narrative

End-to-end analyzer pipeline

How IMP2 source becomes a sound abstract result: compile to a CFG, build constraint right-hand sides, run the vendored top-down solver, and show that the post-fixpoint γ-concretization over-approximates cfg_collect at every program point — not only at exit. The collecting semantics is the specification; runs_to is exit sugar linked to small-step termination. 

x ::= N 1;;
WHILE Less (N 0) (V x) DO
  x ::= Plus (V x) (N (-1))

Initial store s = (λ_. 0); small-step execution terminates with t x = 0. The sign abstract exit for x must concretize to a set containing 0 — the headline theorem goblint_sign_sound (closed).

00Running example

One program traced through the full chain. Operational reading uses small_step ((c,s) → … → (SKIP, t)); the formal spec uses cfg_collect and runs_to.

Program c

x ::= N 1;;
WHILE Less (N 0) (V x) DO
  x ::= Plus (V x) (N (-1))

Concrete execution

s = (λ_. 0)
-- small_step star terminates -->
t x = 0

runs_to c s t holds (definitional: membership in cfg_collect (to_cfg c) {s} (cfg_exit (to_cfg c))). Bridge: runs_to_iff_small_step in CFG_Runs_To_Bridge.thy.

Target (sign, exit)
t ∈ sign_domain.gamma_state
      (run_analysis (sign_analysis_config s) c
         (cfg_exit (to_cfg c)))

So the abstract sign at exit for x is in {SZero, STop} — its concretization contains 0. Proved as goblint_sign_sound via sign_pipeline_sound.

01Invariant soundness

pipeline_invariant_sound in src/Pipeline/Pipeline.thy — the primary end-to-end statement. Point-map soundness at every program point; exit-only results are corollaries.

Thmpipeline_invariant_sound
∀ v. cfg_collect (to_cfg c) {s} v
      ≤ γ_state (run_analysis cfg c v)

Assumes a generic analysis_config: sound_domain (ac_gamma cfg), domain_transfer_sound for edge transformers, initial store in γ of ac_init cfg, idempotent join (for Finite_Set.fold), join_eq / bot_eq matching ac_join / ac_bot, and TD solver hypotheses (TD_plain.solve_dom, td_cfg_in_reach).

Proof spine (inside the lemma)

(1) td_analyse_post_fixpoint — vendored TD yields is_post_fixpoint on to_cfg c
(2) post_fixpoint_sound — post-fixpoint ⊆ γ ∘ env at every v w.r.t. cfg_collect
(3) Pointwise transfer soundness + monotone rhs (packaged in domain_transfer_sound)
  • td_analyse_post_fixpoint TD_Interface.thy solver output is a post-fixpoint of the constraint system.
  • post_fixpoint_sound Constraint_System_Sound.thy post-fixpoint over-approximates cfg_collect.
  • sign_pipeline_invariant_sound sign instantiation of the invariant (same file).
Design choice

Earlier AST-only exit annotations cannot express assignment soundness in general. The CFG + post-fixpoint story is the main theorem; see docs/PROOF_OVERVIEW.md (“Why not AST annotations”).

02Path soundness

pipeline_sound_path — soundness along any CFG path, including non-terminating programs at intermediate points (Example_NonTerminating_Safe.thy).

Thmpipeline_sound_path
cfg_path (to_cfg c) (cfg_entry (to_cfg c)) es v
⟹ t ∈ edges_collect es {s}
⟹ t ∈ γ_state (run_analysis cfg c v)

Direct consequence of pipeline_invariant_sound and path_sound_cfg_collect (CFG_Path_Bridge.thy): path-collected stores sit inside cfg_collect at v.

Path infrastructure

ConceptWhere
cfg_pathCFG_Path.thy — paths carry edge_action lists
edges_collectFold of edge_collect along actions
cfg_collect_eq_cfg_edges_collectLinks LFP cfg_collect to path-shaped collecting
path_sound_cfg_collectPath stores ⊆ cfg_collect at destination v
Non-termination

If a loop never exits, runs_to gives no conclusion — but pipeline_sound_path still bounds stores reachable inside the loop (e.g. x = 10 after x := 10; while True do skip).

03Exit corollaries

For consumers that want “program runs s to t” wording: specialize the invariant to v = cfg_exit (to_cfg c). Primary spec premise is membership in cfg_collect at exit, not a separate operational rule.

Defruns_to CFG_Runs_To_Bridge.thy
runs_to c s t  ⟺
  t ∈ cfg_collect (to_cfg c) {s} (cfg_exit (to_cfg c))

Not a second semantics — exit projection of cfg_collect.

Thmpipeline_sound_runs_to
t ∈ cfg_collect (to_cfg c) {s}
      (cfg_exit (to_cfg c))
⟹ t ∈ γ_state (run_analysis cfg c
      (cfg_exit (to_cfg c)))
Corpipeline_sound_runs_to_runs
runs_to c s t
⟹ t ∈ γ_state (run_analysis cfg c
      (cfg_exit (to_cfg c)))

One-line unfold via runs_to_def.

Operational link (terminating runs)

  • runs_to_iff_small_step (c,s) →* (SKIP,t) iff runs_to c s t.
  • small_step_runs_to forward: star to SKIP ⇒ runs_to.
  • runs_to_small_step reverse: runs_to ⇒ star to SKIP.

On the running example: prove termination with small-step rules in IMP2, then apply exit corollaries — or use cfg_collect directly as the soundness premise.

04goblint_sign_sound

Top-level thesis entry point in src/Goblint_Formalization.thy. Sign pipeline closed — instantiates generic pipeline lemmas with sign_analysis_config and proved sign transfer functions.

Thmgoblint_sign_sound Goblint_Formalization.thy
runs_to c s t
⟹ TD_plain.solve_dom … (cfg_entry (to_cfg c))
⟹ td_cfg_in_reach …
⟹ comp_fun_idem join on sign abs_state
⟹ t ∈ sign_domain.gamma_state
      (run_analysis (sign_analysis_config s) c
         (cfg_exit (to_cfg c)))

Proof: by (rule sign_pipeline_sound …).

What is proved vs assumed

Discharged in repoExplicit TD hypotheses
sound_domain for sign; sign_tf_sound / domain_transfer_sound; s ∈ γ(ac_init (sign_analysis_config s)); sign_pipeline_sound → sign_analysis_sound → td_solver_sound comp_fun_idem (⊔) on sign join; TD_plain.solve_dom on the generated make_rhs_tree; td_cfg_in_reach — every reachable unknown solved from entry

TD hypotheses are operational (“solver covers this CFG”), not gaps in post_fixpoint_sound. See PROOF_OVERVIEW.

End-to-end chain (sign, exit)

t ∈ cfg_collect (to_cfg c) {s} (cfg_exit …) — spec, or runs_to c s t
⊆ γ_state (env (cfg_exit …)) — post_fixpoint_sound + td_analyse_post_fixpoint
env = td_analyse c sign_tf join bot init — TD_Interface + TD_plain
⇒ goblint_sign_sound
Running example conclusion

For s = λ_. 0 and terminating t with t x = 0, the sign analysis at exit puts x in {SZero, STop}, so 0 ∈ γ_sign … — matching the concrete final value.
