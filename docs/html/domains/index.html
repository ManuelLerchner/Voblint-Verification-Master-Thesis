Goblint Formalization · Abstract Domains

Sign and interval abstract domains

src/Domains/ defines the shared abstract-domain interface (sound_domain, abstract_domain, lifted gamma_state) and two concrete instantiations: sign (finite lattice, closed in the pipeline) and interval (widening for loops, stretch still open). Per-edge transfers are bundled as sign_tf / ivl_tf; the domain_transfer record itself lives in Equations/Constraint_System.thy.

∎Overview

Abstract domains over-approximate sets of concrete stores. The analyzer never reasons about individual integers at a program point; it tracks abstract values per variable and uses sound join and transfer functions when the equation system is solved.

TheoryRole
Abstract_Domain.thy Locales sound_domain and abstract_domain; type synonym 'a abs_state = vname ⇒ 'a; gamma_state; join-fold lemmas for finite predecessor sets.
Sign_Domain.thy Finite sign lattice (SBot … STop), gamma_sign, assign_sign / assume_sign, sign_tf, interpretation sign_domain: abstract_domain.
Interval_Domain.thy Interval lattice with widen_ivl, gamma_ivl, interval transfers, ivl_tf; interpretation ivl_domain: abstract_domain.
Downstream consumers

Equations/Constraint_System.thy builds rhs from a CFG, a domain_transfer, join, and bot. Pipeline/Pipeline.thy packages configs (sign_analysis_config, ivl_analysis_config), proves domain_transfer_sound, and connects to TD solver soundness (sign_pipeline_sound, goblint_sign_sound).

Stretch goal (not in tree)

Octagon domain is planned (Sign → Interval → Octagon) but has no theory file yet. The layering diagram below shows only what is checked in today.

01Locales & gamma_state

From Abstract_Domain.thy: every domain provides concretization, bottom, and a sound join; widening is optional at the locale level.

sound_domain

Parameter gamma :: 'a ⇒ int set with axioms:

  • gamma bot = {}
  • a ≤ b ⟹ gamma a ⊆ gamma b (monotone concretization)

Derived: gamma_sup_sound, lifted gamma_state, and gamma_abs_sup_set_ub for folding joins over finite edge sets (used by equation-system soundness).

abstract_domain

Extends sound_domain with widen :: 'a ⇒ 'a ⇒ 'a:

  • gamma a ⊆ gamma (widen a b)
  • gamma b ⊆ gamma (widen a b)

Needed when the domain has infinite ascending chains (intervals). Finite domains (sign) set widen = join; widening axioms follow from join soundness.

Lifted state concretization

type_synonym 'a abs_state = "vname => 'a"

definition gamma_state :: "'a abs_state => store set" where
  "gamma_state sigma = {s. ∀x. s x ∈ gamma (sigma x)}"

Pointwise bot and ⊔ on abs_state come from HOL’s fun instances for semilattices—no separate lifted-bot definition. Pipeline theorems phrase soundness as t ∈ D.gamma_state (run_analysis …).

Key lemmas (interface layer)

  • gamma_state_mono — abstract order on states lifts to set inclusion.
  • gamma_state_bot — bottom abstract state concretizes to ∅.
  • gamma_state_sup_ub1/2 — join over-approximates each operand state-set.
  • sup_fold_ge / gamma_abs_sup_set_ub — finite join fold is sound for RHS construction.

02Sign domain

Sign_Domain.thy — first concrete domain; finite lattice, no non-trivial widening.

Abstract values

datatype sign = SBot | SNeg | SZero | SPos | STop

Concretization gamma_sign

SBot∅
SNeg{n. n < 0}
SZero{0}
SPos{n. n > 0}
STopUNIV

Imports: Abstract_Domain, Constraint_System (for the sign domain_transfer type), IMP2_SmallStep (expression helpers). Instance: sign :: bounded_semilattice_sup_bot with join = least upper bound in the sign lattice. 

interpretation sign_domain: abstract_domain gamma_sign widen_sign
  (* widen_sign a b = join_sign a b — finite domain *)

definition sign_tf :: "sign domain_transfer" where
  "sign_tf = (| tf_assign      = assign_sign,
                 tf_assume      = assume_sign,
                 tf_assume_not  = assume_not_sign |)"

Per-action soundness (proved in Sign_Domain)

  • assign_sign_sound — assignment refines gamma_state correctly.
  • assume_sign_sound / assume_not_sign_sound — assume edges preserve stores satisfying the guard.
  • sign_gamma_state_conv — sign_domain.gamma_state = sound_domain.gamma_state gamma_sign.
Pipeline status

Sign transfers are wired through sign_analysis_config in Pipeline.thy; end-to-end goblint_sign_sound is closed. See pipeline walkthrough.

03Interval domain

Interval_Domain.thy — Tier-2 domain with proper widening on loops.

Intervals use extended bounds (eint: MinInf, Fin n, PlusInf) so unbounded intervals are representable. Concretization gamma_ivl maps Ivl l u to integer sets (empty when l > u). 

interpretation ivl_domain: abstract_domain gamma_ivl widen_ivl

definition ivl_tf :: "ivl domain_transfer" where
  "ivl_tf = (| tf_assign      = assign_ivl,
                 tf_assume      = assume_ivl,
                 tf_assume_not  = assume_not_ivl |)"

Like sign, interval theory imports Constraint_System only to declare ivl_tf as a domain_transfer record—the record definition is not duplicated here.

Widening

widen_ivl extrapolates bounds so ascending chains in loop headers stabilize. widen_state (from abstract_domain) applies widening pointwise on ivl abs_state. TD solver termination for intervals relies on this plus the widen locale axioms.

Proof status

Sign end-to-end is closed (goblint_sign_sound). Interval packaging (ivl_pipeline_sound) is proved in Pipeline.thy; see docs/PROOF_PHASES.md for stretch goals and open items.

04Transfer soundness

Single-edge transfers must map abstract stores to larger concrete set over-approximations.

domain_transfer (Equations layer)

Defined in Constraint_System.thy:

record 'a domain_transfer =
  tf_assign     :: "vname => aexp => ('a abs_state) => ('a abs_state)"
  tf_assume     :: "bexp  => ('a abs_state) => ('a abs_state)"
  tf_assume_not :: "bexp => ('a abs_state) => ('a abs_state)"

fun apply_tf :: "'a domain_transfer => edge_action => ..."

rhs folds apply_tf tf a over predecessor edges and joins with ⊔. The equation-system soundness proof assumes transfers satisfy the gamma-state conditions bundled below.

domain_transfer_sound (Pipeline layer)

Defined in Pipeline.thy — packages the three standard conditions:

domain_transfer_sound gamma tf ⟷
  (∀ assign: stores in γ_state sigma stay in γ_state after tf_assign)
  ∧ (∀ assume b:  bval b s ⟹ s ∈ γ_state (tf_assume tf b sigma))
  ∧ (∀ assume ¬b: ¬bval b s ⟹ s ∈ γ_state (tf_assume_not tf b sigma))
