# Historical documents

Completed migration notes, handoffs, audits and plans. They record how the
repository reached its current shape; none of them describes it.

Read them only to reconstruct a decision's history. For what the system is
now, start at `../INDEX.md` — the source theories remain authoritative for
definitions and theorem statements, and any figure or file path quoted below
is from the tree as it stood when the note was written.
