\begin{abstract}
Goblint-style abstract interpreters translate a program into side-effecting
equations, with one unknown per program point and calling context, and solve
them with a generic solver. The partial correctness of that solver has been
verified in Isabelle/HOL, but the theorem does not connect the equations to
the program. We mechanize this connection for a small imperative language with
recursive procedures.
We adapt the local traces of Schwarz et al.\ to procedure activations,
because a return must resume exactly the activation that made the call. A
context policy relates each activation trace to the calling contexts it may
belong to. The development provides (i) a coverage contract of five local
obligations over an arbitrary control-flow graph, which bounds every valid
trace in every admitted context; (ii) a proof
that every post-solution of the generated, context-routed equations meets the
contract, using the verified solver only through its certificate; and (iii) an
end-to-end theorem from a small-step source semantics to the verdicts of the
analyzer function that Isabelle exports to OCaml, for every configuration it
offers. The guarantee is per program point: every reached store is covered by
the report and satisfies its definite verdicts. It is partial correctness,
since solver termination is not proved, and the language has no pointers or
heap.
\end{abstract}
