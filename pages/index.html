Run the analyzer

A thin CLI around verified code

pixi run voblint builds a small command-line harness around the formally verified OCaml export. The parser and file handling live in the CLI; analysis and reporting run through the generated Voblint_CLI module. 

pixi run voblint \
  --analysis int FILE.vimp

The same generated code powers the regression suite, GraphViz output, and browsable HTML reports. The repository's VIMP fixtures show concrete commands and expected results.
