Theory Run_Report

theory Run_Report
  imports Analysis_Report
begin

section ‹The report of a run›

text ‹
  A run is reported by \<^const>‹report_of›: the elaborated graph, the declared variables,
  the globals the placement keeps at unknowns of their own, the arithmetic obligations of
  the graph's expressions, and the program's procedures.
›

subsection ‹Arithmetic obligations of typed expressions›

text ‹
  A division or remainder must not divide by zero. A signed addition, subtraction,
  multiplication or division must compute a result its kind represents: C leaves the
  behavior undefined otherwise (ISO/IEC 9899 6.5p5), and Goblint checks the same four
  operators (▩‹SignedIntegerOverflowInArithmetic›). A unary minus reaches the
  typed language as a subtraction from zero, and a signed division overflows only on
  the kind's minimum divided by ‹-1›. A signed remainder's mathematical result
  always fits, but C leaves it undefined when the quotient does not fit (6.5.5p6), as for
  ‹INT_MIN % -1›: its obligation is that the truncated quotient fits. An unsigned
  operation wraps by definition and raises no obligation.

  A conversion must convert a value its target kind represents. Elaboration makes
  every conversion a ‹TCast› node: an explicit cast, and the implicit conversions of an
  assigned value, an argument and a returned value to the kind of the place they are
  written to. A conversion whose source kind widens into its target cannot change a
  value of the source kind and raises no obligation. Goblint checks conversions to
  signed and unsigned kinds alike (‹IntegerOverflowInExplicitCast›,
  ‹…InImplicitCast›); so does Voblint, although C defines a conversion to an unsigned
  kind as wraparound and leaves one to a signed kind implementation-defined, not
  undefined. Voblint does not tell an explicit cast from an implicit conversion, since
  elaboration does not record it.

  Every obligation of an expression is raised, however deeply it is nested and
  whatever the value of an enclosing logical operator, since the typed language
  evaluates both operands of one.
›

text ‹A literal elaborated at a kind is converted to it as well: ‹x = 300› for an 8-bit
  ‹x› elaborates to the literal at ‹x›'s kind, whose value wraps.›

fun arith_obligations :: "exp ⇒ exp arithmetic_obligation list" where
  "arith_obligations (TN k n) =
     (if n ∈ ik_range k then [] else [Arithmetic_Obligation Conversion_Overflow (TN k n) (TN k n)])"
| "arith_obligations (TVar _ _) = []"
| "arith_obligations (TArith k op a b) =
     arith_obligations a @ arith_obligations b
     @ (if op = ADiv ∨ op = AMod
        then [Arithmetic_Obligation Division_By_Zero (TArith k op a b) b] else [])
     @ (if ¬ ik_signed k then []
        else if op = AMod
        then [Arithmetic_Obligation Remainder_Overflow (TArith k op a b) (TArith k ADiv a b)]
        else [Arithmetic_Obligation Signed_Overflow (TArith k op a b) (TArith k op a b)])"
| "arith_obligations (TCast k a) =
     arith_obligations a
     @ (if ik_widens (exp_kind a) k then []
        else [Arithmetic_Obligation Conversion_Overflow (TCast k a) a])"
| "arith_obligations (TCmp _ a b) = arith_obligations a @ arith_obligations b"
| "arith_obligations (TNot a) = arith_obligations a"
| "arith_obligations (TAnd a b) = arith_obligations a @ arith_obligations b"
| "arith_obligations (TOr a b) = arith_obligations a @ arith_obligations b"

text ‹A division obligation is safe when its divisor is not zero, compared at the divisor's
  kind.›

definition arith_condition :: "exp arithmetic_obligation ⇒ exp" where
  "arith_condition ob =
     TCmp CNe (arithmetic_operand ob) (TN (exp_kind (arithmetic_operand ob)) 0)"

text ‹
  An overflow obligation is about the value an operation computes before its kind
  wraps it: the mathematical result of an arithmetic node, the converted value of a
  conversion, the quotient a remainder's operand names, and the minimum or maximum of a
  library result's two arguments. It is safe when that value lies in the operation's
  kind. The statement does
  not depend on the overflow policy: the policy decides how an analysis abstracts a
  wrapped result, never what the program computes.
›

fun unwrapped :: "exp ⇒ store ⇒ int" where
  "unwrapped (TN k n) t = n"
| "unwrapped (TArith k op a b) t = aop_eval op (eval a t) (eval b t)"
| "unwrapped (TCast k a) t = eval a t"
| "unwrapped e t = eval e t"

definition obligation_holds :: "exp arithmetic_obligation ⇒ store ⇒ bool" where
  "obligation_holds ob t ⟷
     (let k = exp_kind (arithmetic_operation ob); m = unwrapped (arithmetic_operation ob) t;
          n = eval (arithmetic_operand ob) t
      in case arithmetic_hazard ob of
           Division_By_Zero ⇒ n ≠ 0
         | Min_Conversion_Overflow ⇒ min m n ∈ ik_range k
         | Max_Conversion_Overflow ⇒ max m n ∈ ik_range k
         | Remainder_Overflow ⇒ unwrapped (arithmetic_operand ob) t ∈ ik_range k
         | _ ⇒ m ∈ ik_range k)"

abbreviation satisfies :: "store ⇒ exp arithmetic_obligation ⇒ bool" (infix "⊨" 50) where
  "s ⊨ ob ≡ obligation_holds ob s"

text ‹
  An overflow obligation is decided as Goblint decides it, from the interval of the
  unwrapped result: the operands' values are asked through ‹EvalInt›, so every active
  analysis contributes, and their interval components are combined by the operation
  over the integers. The obligation is safe when that interval lies in the kind, and
  certainly violated when it misses the kind. An answer that admits no value is
  read as unknown, as \<^const>‹answer_check› reads one.
›

text ‹A literal operand is its own exact interval, a truth value lies in ‹[0, 1]›, and
  any other operand lies in its kind's range when its kind is known
  (\<^const>‹src_kind›), whatever the active analyses answer for it: a domain without
  magnitudes, such as Parity, would otherwise leave even ‹10 / 3› or ‹x / 2› a
  possible overflow. The kind bounds an operand only at a store within the kinds
  (\<^const>‹in_kinds›), which every reaching store is. A conversion whose operand's
  interval lies in the target kind changes no value, so it keeps that interval: a
  \<^const>‹U8› argument of ‹min› promoted to \<^const>‹I32› stays within
  ‹[0, 255]›.›

fun operand_ivl :: "kenv ⇒ channel ⇒ exp ⇒ ivl" where
  "operand_ivl κ ch (TN k n) = Ivl (Fin (ik_norm k n)) (Fin (ik_norm k n))"
| "operand_ivl κ ch (TCmp c a b) =
     of_answer_ik None (ch (EvalInt (TCmp c a b))) ⊓ Ivl (Fin 0) (Fin 1)"
| "operand_ivl κ ch (TNot a) =
     of_answer_ik None (ch (EvalInt (TNot a))) ⊓ Ivl (Fin 0) (Fin 1)"
| "operand_ivl κ ch (TAnd a b) =
     of_answer_ik None (ch (EvalInt (TAnd a b))) ⊓ Ivl (Fin 0) (Fin 1)"
| "operand_ivl κ ch (TOr a b) =
     of_answer_ik None (ch (EvalInt (TOr a b))) ⊓ Ivl (Fin 0) (Fin 1)"
| "operand_ivl κ ch (TCast k a) =
     (let i = operand_ivl κ ch a;
          j = of_answer_ik (src_kind κ (TCast k a)) (ch (EvalInt (TCast k a)))
      in if i ≤ ik_ivl k then i ⊓ j else j)"
| "operand_ivl κ ch e = of_answer_ik (src_kind κ e) (ch (EvalInt e))"

fun unwrapped_ivl :: "kenv ⇒ channel ⇒ exp ⇒ ivl" where
  "unwrapped_ivl κ ch (TN k n) = Ivl (Fin n) (Fin n)"
| "unwrapped_ivl κ ch (TArith k op a b) =
     ivl_aop op (operand_ivl κ ch a) (operand_ivl κ ch b)"
| "unwrapped_ivl κ ch (TCast k a) = operand_ivl κ ch a"
| "unwrapped_ivl κ ch e = operand_ivl κ ch e"

lemma unwrapped_ivl_sound:
  assumes "eval_query.channel_holds ch t" and kinds: "in_kinds κ t"
  shows "unwrapped e t ∈ gamma_ivl (unwrapped_ivl κ ch e)"
    and "eval e t ∈ gamma_ivl (operand_ivl κ ch e)"
proof -
  have answer: "eval a t ∈ gamma_ivl (of_answer_ik sk (ch (EvalInt a)))"
    if "⋀k. sk = Some k ⟹ eval a t ∈ ik_range k" for a sk
    using eval_query.channel_holdsD[OF assms(1), of "EvalInt a"]
      of_answer_ik_sound[where 'a = ivl, of sk "eval a t" "ch (EvalInt a)"] that
    by simp
  have truth: "eval a t ∈ gamma_ivl (Ivl (Fin 0) (Fin 1))"
    if
      "a ∈ {TCmp c x y | c x y. True} ∪ range TNot ∪ {TAnd x y | x y. True} ∪ {TOr x y | x y. True}"
    for a
    using that by (auto simp: less_eq_eint_def)
  have known: "eval a t ∈ gamma_ivl (of_answer_ik (src_kind κ a) (ch (EvalInt a)))" for a
    by (rule answer[OF src_kind_sound[OF kinds]])
  have other: "eval a t ∈ gamma_ivl (operand_ivl κ ch a)" if "∀k b. a ≠ TCast k b" for a
    using that answer[of None a] known[of a] truth[of a]
    by (cases a) (auto simp: less_eq_eint_def gamma_inf_ivl)
  have ans: "eval a t ∈ gamma_ivl (operand_ivl κ ch a)" for a
  proof (induction a)
    case (TCast k a)
    have "eval (TCast k a) t = eval a t"
      if "operand_ivl κ ch a ≤ ik_ivl k"
      using gamma_ivl_mono[OF that] TCast.IH by auto
    then show ?case
      using TCast.IH known[of "TCast k a"] by (auto simp: Let_def)
  qed (rule other, simp)+
  show "unwrapped e t ∈ gamma_ivl (unwrapped_ivl κ ch e)"
  proof (cases e)
    case (TN k n) then show ?thesis by (simp add: less_eq_eint_def)
  qed (simp_all only: unwrapped.simps unwrapped_ivl.simps ans ivl_aop_sound)
  show "eval e t ∈ gamma_ivl (operand_ivl κ ch e)" by (rule ans)
qed

definition fits_verdict :: "ikind ⇒ ivl ⇒ check_result" where
  "fits_verdict k i =
     (if is_bottom_ivl i then Check_Unknown
      else if i ≤ ik_ivl k then Check_Proved
      else if is_bottom_ivl (i ⊓ ik_ivl k) then Check_Refuted
      else Check_Unknown)"

lemma fits_verdict_sound:
  assumes "n ∈ gamma_ivl i"
  shows "fits_verdict k i = Check_Proved ⟹ n ∈ ik_range k"
    and "fits_verdict k i = Check_Refuted ⟹ n ∉ ik_range k"
proof -
  show "fits_verdict k i = Check_Proved ⟹ n ∈ ik_range k"
    using assms gamma_ivl_mono[of i "ik_ivl k"]
    by (auto simp: fits_verdict_def split: if_splits)
  show "fits_verdict k i = Check_Refuted ⟹ n ∉ ik_range k"
    using assms
    by (auto simp: fits_verdict_def is_bottom_ivl_correct gamma_inf_ivl split: if_splits)
qed

text ‹A library result's obligation is decided from the minimum or maximum of its
  arguments' intervals, a remainder's from the interval of its quotient.›

definition obligation_classify ::
    "sem_conf ⇒ kind_decls ⇒ analysis list ⇒ exp arithmetic_obligation ⇒ mcp_val
       ⇒ check_result" where
  "obligation_classify sem ds as ob v =
     (let ch = mcp_ask sem ds as v; κ = kenv_of ds; e = arithmetic_operation ob;
          i = unwrapped_ivl κ ch e; j = operand_ivl κ ch (arithmetic_operand ob)
      in case arithmetic_hazard ob of
           Division_By_Zero ⇒ mcp_classify sem ds as (arith_condition ob) v
         | Min_Conversion_Overflow ⇒ fits_verdict (exp_kind e) (ivl_min i j)
         | Max_Conversion_Overflow ⇒ fits_verdict (exp_kind e) (ivl_max i j)
         | Remainder_Overflow ⇒
             fits_verdict (exp_kind e) (unwrapped_ivl κ ch (arithmetic_operand ob))
         | _ ⇒ fits_verdict (exp_kind e) i)"

lemma obligation_classify_sound:
  assumes t: "t ∈ mcp.act_gamma ds as v" and kinds: "in_kinds (kenv_of ds) t"
  shows "obligation_classify sem ds as ob v = Check_Proved ⟹ t ⊨ ob"
    and "obligation_classify sem ds as ob v = Check_Refuted ⟹ ¬ t ⊨ ob"
proof -
  have ch: "eval_query.channel_holds (mcp_ask sem ds as v) t"
    by (rule mcp.mcp_ask_sound[OF t])
  note ivl = unwrapped_ivl_sound[OF ch kinds]
  note fits = fits_verdict_sound[OF ivl(1)]
    and fits_min = fits_verdict_sound[OF ivl_min_sound[OF ivl]]
    and fits_max = fits_verdict_sound[OF ivl_max_sound[OF ivl]]
    and fits_rem = fits_verdict_sound[OF ivl(1)[of "arithmetic_operand ob"]]
  have ne: "truthy (eval (arith_condition ob) t) ⟷ eval (arithmetic_operand ob) t ≠ 0"
    by (simp add: arith_condition_def)
  show "obligation_classify sem ds as ob v = Check_Proved ⟹ t ⊨ ob"
    using fits(1) fits_min(1) fits_max(1) fits_rem(1)
      mcp.mcp_classify_proved[OF t] ne
    by (auto simp: obligation_classify_def obligation_holds_def Let_def
        split: arithmetic_hazard.splits)
  show "obligation_classify sem ds as ob v = Check_Refuted ⟹ ¬ t ⊨ ob"
    using fits(2) fits_min(2) fits_max(2) fits_rem(2)
      mcp.mcp_classify_refuted[OF t] ne
    by (auto simp: obligation_classify_def obligation_holds_def Let_def
        split: arithmetic_hazard.splits)
qed

subsection ‹Where the obligations are decided›

text ‹
  An expression's obligations are decided at the source of the edge or call that
  evaluates it. One conversion has no expression of its own: a call's result, which
  the caller writes to its destination at the destination's kind. Its obligation is
  decided where the callee returns, on the returned expression, once for each kind a
  caller converts it to. A returned value whose kind widens into the destination's
  raises none. A library call's result is written to its destination as well. That of
  ‹min› or ‹max› is decided where the call is, unless both arguments' kinds widen into
  the destination's: the result is one of the arguments. That of the call a declaration
  without an initializer makes is any value of the destination's kind and raises none.
›

definition return_sites ::
    "kind_decls ⇒ imp_prog ⇒ (pp × exp arithmetic_obligation list) list" where
  "return_sites ds p =
     (let g = elab_cfg p ds
      in remdups (concat (map (λ(u, ca, ce, k). case ce_dst ca of
           None ⇒ []
         | Some x ⇒ concat (map (λ(v, a, w). case a of
               EA_Ret (Some e) q ⇒
                 if q = callee_of_entry ce ∧ ¬ ik_widens (exp_kind e) (kenv_of ds x)
                 then [(v, [Arithmetic_Obligation Conversion_Overflow (TCast (kenv_of ds x) e) e])]
                 else []
             | _ ⇒ []) (cfg_intra_list g)))
         (cfg_calls_list g))))"

fun special_obligations :: "ikind ⇒ exp gspecial_call ⇒ exp arithmetic_obligation list" where
  "special_obligations k (Min a b) =
     (if ik_widens (exp_kind a) k ∧ ik_widens (exp_kind b) k then []
      else [Arithmetic_Obligation Min_Conversion_Overflow (TCast k a) b])"
| "special_obligations k (Max a b) =
     (if ik_widens (exp_kind a) k ∧ ik_widens (exp_kind b) k then []
      else [Arithmetic_Obligation Max_Conversion_Overflow (TCast k a) b])"
| "special_obligations k Nondet_Int = []"

definition special_sites ::
    "kind_decls ⇒ imp_prog ⇒ (pp × exp arithmetic_obligation list) list" where
  "special_sites ds p =
     [(v, special_obligations (kenv_of ds x) sc).
        (v, EA_Special sc x, w) ← cfg_intra_list (elab_cfg p ds),
        special_obligations (kenv_of ds x) sc ≠ []]"

definition prog_obligation_sites ::
  "kind_decls ⇒ imp_prog ⇒ (pp × exp arithmetic_obligation list) list" where
  "prog_obligation_sites ds p =
     obligation_sites arith_obligations (elab_cfg p ds) @ return_sites ds p @ special_sites ds p"

text ‹The obligations a report decides at a point, and what it means for a store
  to meet one: ‹s ⊨ ob›.›

definition obligations_at :: "kind_decls ⇒ imp_prog ⇒ pp ⇒ exp arithmetic_obligation set" where
  "obligations_at ds p v = (⋃(u, obs) ∈ set (prog_obligation_sites ds p). if u = v then set obs else {})"

lemma mem_obligations_at:
  "ob ∈ obligations_at ds p v ⟷ (∃obs. (v, obs) ∈ set (prog_obligation_sites ds p) ∧ ob ∈ set obs)"
  by (force simp: obligations_at_def split: if_splits)

text ‹The variables a report lists: every variable an edge or a call of the elaborated
  graph mentions, and the return slot a ‹return e› writes, so the value a procedure
  returns can be shown.›

fun special_vars :: "exp gspecial_call ⇒ var_id list" where
  "special_vars Nondet_Int = []"
| "special_vars (Min a b) = var_list a @ var_list b"
| "special_vars (Max a b) = var_list a @ var_list b"

fun edge_vars :: "(var_id, exp) gedge_action ⇒ var_id list" where
  "edge_vars (EA_Assign x e) = x # var_list e"
| "edge_vars (EA_Special sc x) = x # special_vars sc"
| "edge_vars (EA_Assume b) = var_list b"
| "edge_vars (EA_AssumeNot b) = var_list b"
| "edge_vars (EA_Ret e _) = (case e of Some e ⇒ ReturnVar # var_list e | None ⇒ [])"
| "edge_vars (EA_Check _ e) = var_list e"
| "edge_vars _ = []"

fun call_vars :: "(var_id, exp) gcall_action ⇒ var_id list" where
  "call_vars (CallEdge dst ps args) =
     (case dst of Some x ⇒ [x] | None ⇒ []) @ ps @ concat (map var_list args)"

definition cfg_vars :: "(var_id, exp) gcfg ⇒ var_id list" where
  "cfg_vars g =
     sorted_list_of_set (set (concat (map (λ(u, a, w). edge_vars a) (cfg_intra_list g))
                            @ concat (map (λ(u, ca, e, w). call_vars ca) (cfg_calls_list g))))"

type_synonym report =
  "(voblint_conf, mcp_ctx report_context,
    var_id, exp, var_id, mcp_val) analysis_report"

text ‹One builder for every context policy and placement: the policy contributes how its
  contexts are ordered and tagged, the placement which globals it keeps at their own
  unknowns.›

definition prog_report_of ::
    "voblint_conf ⇒ kind_decls ⇒ imp_prog ⇒ var_id list ⇒ ('c ⇒ order_key)
       ⇒ ('c ⇒ mcp_ctx report_context) ⇒ ('c, var_id, mcp_val) solved_run
       ⇒ report" where
  "prog_report_of conf ds p gs ctx_key ctx_tag sr =
     report_of conf (cfg_vars (elab_cfg p ds)) (elab_cfg p ds) gs
       (prog_obligation_sites ds p) (obligation_classify (conf_sem conf) ds (activation_of (conf_analyses conf)))
       (prog_main_name # prog_procs p) ctx_key ctx_tag
       (mcp_classify (conf_sem conf) ds (activation_of (conf_analyses conf))) sr"

subsection ‹At entry-state contexts›

text ‹
  An entry-state context is listed in the order of an injective key: each field's
  formal values, a kind-tagged value keyed by its tag, its kind and its value.
›

fun ikind_key :: "ikind ⇒ order_key" where
  "ikind_key I8 = Key_Int 0"
| "ikind_key U8 = Key_Int 1"
| "ikind_key I16 = Key_Int 2"
| "ikind_key U16 = Key_Int 3"
| "ikind_key I32 = Key_Int 4"
| "ikind_key U32 = Key_Int 5"
| "ikind_key I64 = Key_Int 6"
| "ikind_key U64 = Key_Int 7"

lemma ikind_key_inject [simp]: "ikind_key a = ikind_key b ⟷ a = b"
  by (cases a; cases b) simp_all

fun kd_key :: "('a ⇒ order_key) ⇒ 'a kd ⇒ order_key" where
  "kd_key f KBot = Key_List [Key_Int 0]"
| "kd_key f (KD k a) = Key_List [Key_Int 1, ikind_key k, f a]"
| "kd_key f KTop = Key_List [Key_Int 2]"

lemma kd_key_inject:
  assumes "⋀a b. f a = f b ⟹ a = b"
  shows "kd_key f x = kd_key f y ⟹ x = y"
  using assms by (cases x; cases y) auto

lemma map_kd_key_inject:
  assumes "⋀a b. f a = f b ⟹ a = b"
  shows "map (kd_key f) xs = map (kd_key f) ys ⟹ xs = ys"
  using kd_key_inject[OF assms] by (auto dest: list.inj_map_strong[rotated])

definition int_tuple_key :: "'m int_tuple ⇒ order_key" where
  "int_tuple_key a = Key_List [ivl_key (it_ivl a), congruence_key (it_cong a)]"

lemma int_tuple_key_inject [simp]: "int_tuple_key a = int_tuple_key b ⟷ a = b"
  unfolding int_tuple_key_def by (cases a; cases b) simp

fun mcp_ctx_key :: "mcp_ctx ⇒ order_key" where
  "mcp_ctx_key (Product i (Product c (Product (Product tn (Product to tf)) (Product s (Product q u))))) =
     Key_List [Key_List (map (kd_key ivl_key) i), Key_List (map (kd_key congruence_key) c),
               Key_List (map (kd_key int_tuple_key) tn), Key_List (map (kd_key int_tuple_key) to),
               Key_List (map (kd_key int_tuple_key) tf), Key_List (map (kd_key sign_key) s),
               Key_List (map (kd_key parity_key) q), Key_List (map (λ_. Key_List []) u)]"

lemma inj_mcp_ctx_key: "inj mcp_ctx_key"
proof (rule injI)
  fix a b :: mcp_ctx
  assume eq: "mcp_ctx_key a = mcp_ctx_key b"
  obtain i c tn to tf s q u
    where a:
      "a = Product i (Product c (Product (Product tn (Product to tf)) (Product s (Product q u))))"
    by (metis analysis_product.exhaust)
  obtain i' c' tn' to' tf' s' q' u'
    where b:
      "b = Product i' (Product c' (Product (Product tn' (Product to' tf')) (Product s' (Product q' u'))))"
    by (metis analysis_product.exhaust)
  from eq have keys:
    "map (kd_key ivl_key) i = map (kd_key ivl_key) i'"
    "map (kd_key congruence_key) c = map (kd_key congruence_key) c'"
    "map (kd_key int_tuple_key) tn = map (kd_key int_tuple_key) tn'"
    "map (kd_key int_tuple_key) to = map (kd_key int_tuple_key) to'"
    "map (kd_key int_tuple_key) tf = map (kd_key int_tuple_key) tf'"
    "map (kd_key sign_key) s = map (kd_key sign_key) s'"
    "map (kd_key parity_key) q = map (kd_key parity_key) q'"
    "map (λ_. Key_List []) u = map (λ_. Key_List []) u'"
    by (simp_all add: a b)
  have "length u = length u'" using keys(8) by (metis length_map)
  then have "u = u'" by (simp add: list_eq_iff_nth_eq)
  moreover have "i = i'" by (rule map_kd_key_inject[OF _ keys(1)]) simp
  moreover have "c = c'" by (rule map_kd_key_inject[OF _ keys(2)]) simp
  moreover have "tn = tn'" by (rule map_kd_key_inject[OF _ keys(3)]) simp
  moreover have "to = to'" by (rule map_kd_key_inject[OF _ keys(4)]) simp
  moreover have "tf = tf'" by (rule map_kd_key_inject[OF _ keys(5)]) simp
  moreover have "s = s'" by (rule map_kd_key_inject[OF _ keys(6)]) simp
  moreover have "q = q'" by (rule map_kd_key_inject[OF _ keys(7)]) simp
  ultimately show "a = b" by (simp add: a b)
qed

subsection ‹The run›

text ‹
  A run solves the equations of the chosen context policy and placement and
  reports the answer; the logical ‹None› branch of the executable solve has no report.
  Under flow-insensitive placement each declared global lives at its own unknown.
›

definition cs_run :: "voblint_conf ⇒ nat ⇒ kind_decls ⇒ imp_prog ⇒ report option" where
  "cs_run conf k ds p =
     (let sem = conf_sem conf; as = conf_analyses conf; r = conf_globals conf;
          key = (λctx. Key_List (map Key_Node ctx));
          tag = (if k = 0 then (λ_. Report_Unit) else Report_Call_String);
          root = (cfg_exit (elab_cfg p ds), [])
      in case conf_program_globals conf of
           Program_Globals_Flow_Sensitive ⇒
             map_option (λsol. prog_report_of conf ds p [] key tag
                                 (mcp_cs.solved_run_of sem ds as k is_global p sol))
               (TD_side_rule_Interp_solve_c r (mcp_cs.equations sem ds as k is_global p) root)
         | Program_Globals_Flow_Insensitive ⇒
             (let gs = declared_globals p
              in map_option (λsol. prog_report_of conf ds p gs key tag
                                     (mcp_split.solved_run_of sem ds as k gs is_global p sol))
                   (TD_side_rule_Interp_solve_c r (mcp_split.equations sem ds as k gs is_global p)
                      root)))"

definition es_run :: "voblint_conf ⇒ kind_decls ⇒ imp_prog ⇒ report option" where
  "es_run conf ds p =
     (let sem = conf_sem conf; as = conf_analyses conf; r = conf_globals conf;
          root = (cfg_exit (elab_cfg p ds), mcp_root_ctx)
      in case conf_program_globals conf of
           Program_Globals_Flow_Sensitive ⇒
             map_option (λsol. prog_report_of conf ds p [] mcp_ctx_key Report_Entry
                                 (mcp_es.solved_run_of sem ds as is_global p sol))
               (TD_side_rule_Interp_solve_c r (mcp_es.equations sem ds as is_global p) root)
         | Program_Globals_Flow_Insensitive ⇒
             (let gs = declared_globals p
              in map_option (λsol. prog_report_of conf ds p gs mcp_ctx_key Report_Entry
                                     (mcp_split_es.solved_run_of sem ds as gs is_global p sol))
                   (TD_side_rule_Interp_solve_c r (mcp_split_es.equations sem ds as gs is_global p)
                      root)))"

definition report_run :: "voblint_conf ⇒ kind_decls ⇒ imp_prog ⇒ report option" where
  "report_run conf ds p =
     (case conf_context conf of
        Call_String k ⇒ cs_run conf k ds p
      | Entry_State ⇒ es_run conf ds p)"

text ‹Every state the solved table holds at a node, at any context, is listed among

lemma report_of_state_mem:

  then show ?thesis by (simp only: report_states_at_report_of[OF fin inj] look)

subsection ‹Soundness›

text ‹
  A report is sound for every store that reaches a node from a store whose globals are
  zero at their kinds. Its diagnostics are sound for the same stores. A point no
  diagnostic names meets every obligation of the expressions evaluated there at every
  store that reaches it; a refuted obligation fails at every such store. Both read the
  diagnostics off the solved table through \<^const>‹obligation_classify›, whichever
  context policy filed it.
›

lemma table_diagnostics_sound:
  fixes rt :: "('c, mcp_val) solved_table"
  assumes fin: "finite (table_contexts rt v)"
    and look: "lookup_table rt v ctx = Lifted st"
    and s: "s ∈ mcp.act_gamma ds as st" and kinds: "in_kinds (kenv_of ds) s"
  shows table_diagnostics_safe:
      "(v, obs) ∈ set sites ⟹ ob ∈ set obs
         ⟹ ∀d ∈ set (arithmetic_diagnostics sites rt (obligation_classify sem ds as)).
               diagnostic_point d ≠ v
         ⟹ s ⊨ ob"
    and table_diagnostics_refuted:
      "d ∈ set (arithmetic_diagnostics sites rt (obligation_classify sem ds as))
         ⟹ diagnostic_verdict d = Check_Refuted ⟹ diagnostic_point d = v
         ⟹ ¬ s ⊨ diagnostic_obligation d"
proof -
  let ?cl = "obligation_classify sem ds as"
  show "s ⊨ ob"
    if site: "(v, obs) ∈ set sites" and ob: "ob ∈ set obs"
      and absent: "∀d ∈ set (arithmetic_diagnostics sites rt ?cl). diagnostic_point d ≠ v"
  proof -
    have "point_verdict rt ?cl v ob = Lifted Check_Proved"
      using arithmetic_diagnostics_absent[OF site ob absent]
        point_verdict_not_dead[OF fin look, of ?cl ob]
      by auto
    then have "?cl ob st = Check_Proved"
      by (rule point_verdict_decided[OF _ _ look]) simp
    then show ?thesis by (rule obligation_classify_sound(1)[OF s kinds])
  qed
  show "¬ s ⊨ diagnostic_obligation d"
    if d: "d ∈ set (arithmetic_diagnostics sites rt ?cl)"
      and r: "diagnostic_verdict d = Check_Refuted" and v: "diagnostic_point d = v"
  proof -
    have "point_verdict rt ?cl v (diagnostic_obligation d) = Lifted Check_Refuted"
      using arithmetic_diagnostics_refuted[OF d r] v by simp
    then have "?cl (diagnostic_obligation d) st = Check_Refuted"
      by (rule point_verdict_decided[OF _ _ look]) simp
    then show ?thesis by (rule obligation_classify_sound(2)[OF s kinds])
  qed
qed

text ‹
  Everything a report guarantees, in one predicate: it lists a row for every check
  edge, and at every store that reaches a node the store lies in a state the report
  lists there, no check there is dead, a proved check holds and a refuted one fails, a
  point no diagnostic names meets every obligation decided there, and a refuted
  obligation fails.
›

definition report_sound :: "voblint_conf ⇒ kind_decls ⇒ imp_prog ⇒ report ⇒ bool" where
  "report_sound conf ds p res ⟷
     (∀v l e w. (v, EA_Check l e, w) ∈ intra (elab_cfg p ds) ⟶
        (∃chk ∈ set (report_checks res). check_point chk = v ∧ check_label chk = l ∧ check_exp chk = e))
   ∧ (∀v s. s ∈ reaching ds p v ⟶
        (∃d. Lifted d ∈ report_states_at res v ∧ s ∈ mcp.act_gamma ds (activation_of (conf_analyses conf)) d)
      ∧ (∀chk ∈ set (report_checks res). check_point chk = v ⟶
           check_verdict chk ≠ Dead
         ∧ (check_verdict chk = Decided Check_Proved ⟶ truthy (eval (check_exp chk) s))
         ∧ (check_verdict chk = Decided Check_Refuted ⟶ ¬ truthy (eval (check_exp chk) s)))
      ∧ (∀obs ob. (v, obs) ∈ set (prog_obligation_sites ds p) ⟶ ob ∈ set obs ⟶ SAFE res v ⟶ s ⊨ ob)
      ∧ (∀d ∈ set (report_diagnostics res). diagnostic_verdict d = Check_Refuted
           ⟶ diagnostic_point d = v ⟶ ¬ s ⊨ diagnostic_obligation d))"

text ‹
  A report built from a solved table is sound when the table covers every reaching
  store, whichever context policy and placement filed it. The table's states are listed
  and its verdicts reported, so each guarantee is read off the state a reaching store
  lies in. A well-formed program keeps every reaching store within its kinds, which
  the diagnostics read.
›

lemma prog_report_of_sound:
  fixes sr :: "('c, var_id, mcp_val) solved_run"
  assumes wf: "wf_program_compile_input p"
    and fin: "finite (covered_keys (run_table sr))" and inj: "inj ctx_key"
    and node: "⋀v. reaching ds p v ⊆ (⋃ctx. mcp.act_gamma ds (activation_of (conf_analyses conf))
                 (case lookup_table (run_table sr) v ctx of Bot ⇒ ⊥ | Lifted st ⇒ st))"
  shows "report_sound conf ds p (prog_report_of conf ds p gs ctx_key ctx_tag sr)"
proof -
  let ?res = "prog_report_of conf ds p gs ctx_key ctx_tag sr"
  let ?rt = "run_table sr"
  let ?as = "activation_of (conf_analyses conf)" and ?sem = "conf_sem conf"
  let ?cl = "mcp_classify ?sem ds ?as"
  have checks: "report_checks ?res = result_checks_of (elab_cfg p ds) ?rt ?cl"
    and diags: "report_diagnostics ?res
                  = arithmetic_diagnostics (prog_obligation_sites ds p) ?rt (obligation_classify ?sem ds ?as)"
    by (simp_all add: prog_report_of_def report_of_def Let_def)
  have fin_g: "finite (intra (elab_cfg p ds))" by (simp add: elab_cfg_def compile_prog_finite)
  have rows: "∃chk ∈ set (report_checks ?res). check_point chk = v ∧ check_label chk = l
                ∧ check_exp chk = e"
    if "(v, EA_Check l e, w) ∈ intra (elab_cfg p ds)" for v l e w
    using that fin_g by (force simp: checks result_checks_of_def)
  have at: "(∃d. Lifted d ∈ report_states_at ?res v ∧ s ∈ mcp.act_gamma ds ?as d)
      ∧ (∀chk ∈ set (report_checks ?res). check_point chk = v ⟶
           check_verdict chk ≠ Dead
         ∧ (check_verdict chk = Decided Check_Proved ⟶ truthy (eval (check_exp chk) s))
         ∧ (check_verdict chk = Decided Check_Refuted ⟶ ¬ truthy (eval (check_exp chk) s)))
      ∧ (∀obs ob. (v, obs) ∈ set (prog_obligation_sites ds p) ⟶ ob ∈ set obs ⟶ SAFE ?res v ⟶ s ⊨ ob)
      ∧ (∀d ∈ set (report_diagnostics ?res). diagnostic_verdict d = Check_Refuted
           ⟶ diagnostic_point d = v ⟶ ¬ s ⊨ diagnostic_obligation d)"
    if s: "s ∈ reaching ds p v" for v s
  proof -
    obtain ctx st where look: "lookup_table ?rt v ctx = Lifted st"
      and st: "s ∈ mcp.act_gamma ds ?as st"
      using node[of v] s by (auto simp: mcp.act_gamma_bot split: lifted.splits)
    have fin_v: "finite (table_contexts ?rt v)" using fin unfolding table_contexts_def by simp
    have states: "Lifted st ∈ report_states_at ?res v"
      unfolding prog_report_of_def by (rule report_of_state_mem[OF fin inj look])
    have check: "check_verdict chk ≠ Dead
        ∧ (check_verdict chk = Decided Check_Proved ⟶ truthy (eval (check_exp chk) s))
        ∧ (check_verdict chk = Decided Check_Refuted ⟶ ¬ truthy (eval (check_exp chk) s))"
      if mem: "chk ∈ set (report_checks ?res)" and pt: "check_point chk = v" for chk
    proof -
      from mem obtain u and a :: "(var_id, exp) gedge_action" where chk0: "chk = ⦇check_point = u, check_label = ea_check_label a,
          check_exp = ea_check_cond a, check_verdict = point_verdict ?rt ?cl u (ea_check_cond a)⦈"
        unfolding checks result_checks_of_def by auto
      with pt have chk: "chk = ⦇check_point = v, check_label = ea_check_label a,
          check_exp = ea_check_cond a, check_verdict = point_verdict ?rt ?cl v (ea_check_cond a)⦈"
        by simp
      have decided: "?cl (ea_check_cond a) st = r"
        if "point_verdict ?rt ?cl v (ea_check_cond a) = Decided r" and "r ≠ Check_Unknown" for r
        by (rule point_verdict_decided[OF that look])
      show ?thesis
        using point_verdict_not_dead[OF fin_v look, of ?cl "ea_check_cond a"]
          decided[of Check_Proved] decided[of Check_Refuted]
          mcp.mcp_classify_proved[OF st] mcp.mcp_classify_refuted[OF st]
        by (auto simp: chk)
    qed
    have kinds: "in_kinds (kenv_of ds) s"
      using node_collect_in_kinds[OF calls_in_kinds_elab_cfg[OF wf] init_stores_in_kinds] s
      by blast
    note diag = table_diagnostics_sound[OF fin_v look st kinds, where sem = ?sem]
    show ?thesis using states st check diag unfolding diags by blast
  qed
  show ?thesis unfolding report_sound_def using rows at by blast
qed

text ‹
  Every answered run is sound. The executable solve's answer is the run the typed
  theorems are about (‹solve_c_run›), so its table covers every reaching store
  (‹mcp_cs_node_sound› and its siblings for the other policy and placement).

lemma report_run_sound:

      and ?tag = "if k = 0 then (λ_. Report_Unit) else Report_Call_String"
    show ?thesis

      from run obtain sol where

            Program_Globals_Flow_Sensitive Let_def dg_pipeline.root_query_def)

  next

    show ?thesis

        by (auto simp: report_run_def es_run_def Entry_State
            Program_Globals_Flow_Sensitive Let_def dg_pipeline.root_query_def)
      note solved = mcp_es.solve_c_run[OF sol]

        unfolding res

           (use solved mcp_es.vars_finite_of_terminates[OF solved(1)]

text ‹Every obligation of an expression an edge or a call evaluates is one the report
  decides at the edge's or the call's source, every conversion of a call's result is
  one it decides where the callee returns, and every conversion of a library result one
  it decides at the library call.›

lemma prog_obligation_site:
  assumes "(v, es) ∈ set (arithmetic_expression_sites (elab_cfg p ds))"
    and "e ∈ set es" and "ob ∈ set (arith_obligations e)"
  shows "∃obs. (v, obs) ∈ set (prog_obligation_sites ds p) ∧ ob ∈ set obs"
  using assms unfolding prog_obligation_sites_def obligation_sites_def by force

lemma prog_obligation_site_intra:
  assumes "(v, a, w) ∈ intra (elab_cfg p ds)"
    and "e ∈ set (edge_expressions a)" and "ob ∈ set (arith_obligations e)"
  shows "∃obs. (v, obs) ∈ set (prog_obligation_sites ds p) ∧ ob ∈ set obs"
  using assms
  by (intro prog_obligation_site[OF arithmetic_expression_sites_intra])
     (simp_all add: elab_cfg_def compile_prog_finite)

lemma prog_obligation_site_call:
  assumes "(v, ca, ce, k) ∈ calls (elab_cfg p ds)"
    and "e ∈ set (ce_args ca)" and "ob ∈ set (arith_obligations e)"
  shows "∃obs. (v, obs) ∈ set (prog_obligation_sites ds p) ∧ ob ∈ set obs"
  using assms
  by (intro prog_obligation_site[OF arithmetic_expression_sites_call])
     (simp_all add: elab_cfg_def compile_prog_finite)

lemma prog_obligation_site_return:
  assumes call: "(u, ca, ce, k) ∈ calls (elab_cfg p ds)" and dst: "ce_dst ca = Some x"
    and ret: "(v, EA_Ret (Some e) (callee_of_entry ce), w) ∈ intra (elab_cfg p ds)"
    and narrows: "¬ ik_widens (exp_kind e) (kenv_of ds x)"
  shows "(v, [Arithmetic_Obligation Conversion_Overflow (TCast (kenv_of ds x) e) e])
           ∈ set (prog_obligation_sites ds p)"
proof -
  have fin: "finite (intra (elab_cfg p ds))" "finite (calls (elab_cfg p ds))"
    by (simp_all add: elab_cfg_def compile_prog_finite)
  have "(u, ca, ce, k) ∈ set (cfg_calls_list (elab_cfg p ds))"
    and "(v, EA_Ret (Some e) (callee_of_entry ce), w) ∈ set (cfg_intra_list (elab_cfg p ds))"
    using call ret fin by simp_all
  then show ?thesis
    unfolding prog_obligation_sites_def return_sites_def Let_def
    using dst narrows by (force simp: image_iff)
qed

lemma prog_obligation_site_special:
  assumes "(v, EA_Special sc x, w) ∈ intra (elab_cfg p ds)"
    and "ob ∈ set (special_obligations (kenv_of ds x) sc)"
  shows "(v, special_obligations (kenv_of ds x) sc) ∈ set (prog_obligation_sites ds p)"
proof -
  have mem: "(v, EA_Special sc x, w) ∈ set (cfg_intra_list (elab_cfg p ds))"
    using assms(1) by (simp add: elab_cfg_def compile_prog_finite)
  have "special_obligations (kenv_of ds x) sc ≠ []" using assms(2) by auto
  then have "(v, special_obligations (kenv_of ds x) sc) ∈ set (special_sites ds p)"
    unfolding special_sites_def by (auto intro!: bexI[OF _ mem])
  then show ?thesis by (simp add: prog_obligation_sites_def)
qed

text ‹What an obligation of each hazard says about a store.›

lemma obligation_holds_overflow [simp]:
  "t ⊨ Arithmetic_Obligation Signed_Overflow (TArith k op a b) x
     ⟷ aop_eval op (eval a t) (eval b t) ∈ ik_range k"
  by (simp add: obligation_holds_def Let_def)

lemma obligation_holds_conversion [simp]:
  "t ⊨ Arithmetic_Obligation Conversion_Overflow (TCast k a) x
     ⟷ eval a t ∈ ik_range k"
  "t ⊨ Arithmetic_Obligation Conversion_Overflow (TN k n) x ⟷ n ∈ ik_range k"
  by (simp_all add: obligation_holds_def Let_def)

lemma obligation_holds_remainder [simp]:
  "t ⊨ Arithmetic_Obligation Remainder_Overflow (TArith k AMod a b) (TArith k ADiv a b)
     ⟷ c_div (eval a t) (eval b t) ∈ ik_range k"
  by (simp add: obligation_holds_def Let_def)

lemma obligation_holds_min_max [simp]:
  "t ⊨ Arithmetic_Obligation Min_Conversion_Overflow (TCast k a) b
     ⟷ min (eval a t) (eval b t) ∈ ik_range k"
  "t ⊨ Arithmetic_Obligation Max_Conversion_Overflow (TCast k a) b
     ⟷ max (eval a t) (eval b t) ∈ ik_range k"
  by (simp_all add: obligation_holds_def Let_def)

lemma obligation_holds_division [simp]:
  "t ⊨ Arithmetic_Obligation Division_By_Zero e b ⟷ eval b t ≠ 0"
  by (simp add: obligation_holds_def Let_def)

text ‹An expression raises an obligation for each of its nodes that can fail, at any
  depth.›

fun subexps :: "exp ⇒ exp set" where
  "subexps (TArith k op a b) = insert (TArith k op a b) (subexps a ∪ subexps b)"
| "subexps (TCast k a) = insert (TCast k a) (subexps a)"
| "subexps (TCmp c a b) = insert (TCmp c a b) (subexps a ∪ subexps b)"
| "subexps (TNot a) = insert (TNot a) (subexps a)"
| "subexps (TAnd a b) = insert (TAnd a b) (subexps a ∪ subexps b)"
| "subexps (TOr a b) = insert (TOr a b) (subexps a ∪ subexps b)"
| "subexps e = {e}"

lemma arith_obligations_overflow:
  "TArith k op a b ∈ subexps e ⟹ ik_signed k ⟹ op ≠ AMod
     ⟹ Arithmetic_Obligation Signed_Overflow (TArith k op a b) (TArith k op a b)
           ∈ set (arith_obligations e)"
  by (induction e) auto

lemma arith_obligations_remainder:
  "TArith k AMod a b ∈ subexps e ⟹ ik_signed k
     ⟹ Arithmetic_Obligation Remainder_Overflow (TArith k AMod a b) (TArith k ADiv a b)
           ∈ set (arith_obligations e)"
  by (induction e) auto

lemma arith_obligations_conversion:
  "TCast k a ∈ subexps e ⟹ ¬ ik_widens (exp_kind a) k
     ⟹ Arithmetic_Obligation Conversion_Overflow (TCast k a) a ∈ set (arith_obligations e)"
  by (induction e) auto

subsection ‹Rendering a report›

text ‹
  A report is rendered by \<^const>‹render_report› with a renderer of its own: each active
  analysis shows a kind-tagged value per variable, the order analysis its facts, and an
  entry-state context the formal values of its active fields. An edge's footprint names
  the globals it reads and writes among those kept at their own unknowns: none under
  \<^const>‹Program_Globals_Flow_Sensitive›, the declared globals it touches under
  \<^const>‹Program_Globals_Flow_Insensitive›.
›

instantiation order_rel :: (type) join_val
begin
definition vjoin_order_rel :: "'v order_rel ⇒ 'v order_rel ⇒ 'v order_rel" where
  "vjoin_order_rel = sup"
instance ..
end

text ‹An Int value prints the same at every refinement mode, so the report drops the mode.›

definition it_untag :: "'m int_tuple ⇒ unit int_tuple" where
  "it_untag a = IT (it_ivl a) (it_cong a)"

datatype report_value =
    Interval_Value "ivl kd"
  | Congruence_Value "congruence kd"
  | Int_Value "unit int_tuple kd"
  | Sign_Value "sign kd"
  | Parity_Value "parity kd"
  | Order_Value "(vname × vname) list option"

fun string_of_report_value :: "report_value ⇒ String.literal" where
  "string_of_report_value (Interval_Value v) = to_string v"
| "string_of_report_value (Congruence_Value v) = to_string v"
| "string_of_report_value (Int_Value v) = to_string v"
| "string_of_report_value (Sign_Value v) = to_string v"
| "string_of_report_value (Parity_Value v) = to_string v"
| "string_of_report_value (Order_Value v) = order_view_string v"

text ‹A variable is shown by its name, qualified by its procedure when it is local.›

fun var_label :: "var_id ⇒ vname" where
  "var_label (GlobalId x) = x"
| "var_label (ScopedId f x) = f + STR ''::'' + x"
| "var_label (ReturnId f) = f + STR ''::return''"
| "var_label ReturnVar = STR ''return''"

definition field_view ::
    "('a kd ⇒ report_value) ⇒ var_id list ⇒ 'a tabs lifted ⇒ report_value field_state" where
  "field_view mk vars d =
     Field_Store (map (λx. (var_label x, mk (case d of Bot ⇒ KBot | Lifted σ ⇒ σ x))) vars)"

text ‹An order fact relates variables of one procedure's state, so it names each by its
  own name.›

fun order_var_label :: "var_id ⇒ vname" where
  "order_var_label (ScopedId f x) = x"
| "order_var_label x = var_label x"

definition order_field_view :: "var_id order_rel lifted ⇒ report_value field_state" where
  "order_field_view d =
     Field_Whole (Order_Value (case d of
        Lifted (OFacts _ ps) ⇒
          Some (map (λ(a, b). (order_var_label a, order_var_label b)) (sorted_list_of_set ps))
      | _ ⇒ None))"

definition render ::
    "analysis list ⇒ var_id list ⇒ mcp_val ⇒ (analysis, report_value) analysis_view" where
  "render as vars v = map (λa. (a, case a of
       Interval ⇒ field_view Interval_Value vars (slot1 v)
     | Congruence ⇒ field_view Congruence_Value vars (slot2 v)
     | Ana_Int Refine_Never ⇒ field_view (Int_Value ∘ map_kd it_untag) vars (slot3n v)
     | Ana_Int Refine_Once ⇒ field_view (Int_Value ∘ map_kd it_untag) vars (slot3o v)
     | Ana_Int Refine_Fixpoint ⇒ field_view (Int_Value ∘ map_kd it_untag) vars (slot3f v)
     | Sign ⇒ field_view Sign_Value vars (slot4 v)
     | Parity ⇒ field_view Parity_Value vars (slot5 v)
     | Order ⇒ order_field_view (slot6 v))) as"

fun context_values :: "analysis list ⇒ mcp_ctx ⇒ report_value list" where
  "context_values as (Product i (Product c (Product (Product tn (Product to tf)) (Product s (Product q u))))) =
     concat (map (λa. case a of
         Interval ⇒ map Interval_Value i
       | Congruence ⇒ map Congruence_Value c
       | Ana_Int Refine_Never ⇒ map (Int_Value ∘ map_kd it_untag) tn
       | Ana_Int Refine_Once ⇒ map (Int_Value ∘ map_kd it_untag) to
       | Ana_Int Refine_Fixpoint ⇒ map (Int_Value ∘ map_kd it_untag) tf
       | Sign ⇒ map Sign_Value s
       | Parity ⇒ map Parity_Value q
       | Order ⇒ []) as)"

text ‹The globals an edge or a call reads and writes, among those kept at their own
  unknowns.›

definition footprints :: "(var_id, exp, var_id) footprints" where
  "footprints =
     ⦇ fp_edge_reads = edge_global_reads, fp_edge_writes = edge_global_writes,
       fp_call_reads = call_global_reads,
       fp_call_writes = (λG ca. case ca of CallEdge dst pars args ⇒
         global_names_in G (case_option [] (λx. [x]) dst @ pars)) ⦈"

definition renderer ::
    "(voblint_conf, mcp_ctx, mcp_val, var_id, exp, var_id,
      analysis, report_value) report_renderer" where
  "renderer =
     ⦇ rr_view = (λconf. render (activation_of (conf_analyses conf))),
       rr_context = (λconf. context_values (activation_of (conf_analyses conf))),
       rr_footprints = footprints ⦈"

definition prog_render_report ::
    "(report_value ⇒ 'v) ⇒ report ⇒ (var_id, exp, var_id, analysis, 'v) run_result" where
  "prog_render_report = render_report renderer"
