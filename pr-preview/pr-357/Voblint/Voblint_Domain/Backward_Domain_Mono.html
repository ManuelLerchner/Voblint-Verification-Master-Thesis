section ‹Monotone inverse operators›

text ‹A domain states its inverse operators' monotonicity with ‹le_pair›.›

subsection ‹Pairwise order for reductive/monotone inverse operators›

text ‹
  A minimal componentwise order on ‹'a * 'a›, used only to state each inverse
  operator's monotonicity and reductiveness as a single fact about its returned
  pair rather than as two separately-assumed projections. Deliberately not
  ‹'a * 'a›'s own ‹≤›: some already-transitively-imported theory instantiates
  ‹('a,'b) prod :: order› here with a non-componentwise (order-with-a-‹<›-disjunct)
  definition, so relying on the ambient ‹≤› would silently pick up the wrong
  relation. This local, self-contained ‹≤_pair› avoids that entirely.
›

abbreviation le_pair :: "'a::order × 'a ⇒ 'a × 'a ⇒ bool" where
  "le_pair p q ≡ fst p ≤ fst q ∧ snd p ≤ snd q"

end
