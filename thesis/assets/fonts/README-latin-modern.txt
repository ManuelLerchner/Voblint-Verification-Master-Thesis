Latin Modern fonts
==================

Latin Modern (GUST e-foundry) is the OpenType release of Computer Modern with
the same metrics and design sizes, which is what lets the thesis reproduce the
TUM LaTeX template's cmr17 / cmr12 / cmbx12 / cmr10 / cmssbx10 usage size for
size. The files are copied unchanged from TeX Live 2026
(texmf-dist/fonts/opentype/public/lm and lm-math) and are licensed under the
GUST Font License in LICENSE-latin-modern.txt.
